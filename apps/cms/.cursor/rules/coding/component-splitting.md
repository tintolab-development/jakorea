# 컴포넌트 분리 룰

## 분리 기준

| 줄수 | 조치 |
|---|---|
| ~200줄 | 정상 범위 — 분리 불필요 |
| 200~300줄 | 분리 권장 — 독립적인 섹션이 있으면 추출 |
| 300줄 이상 | **반드시 분리** — 작업 진행 중이라도 즉시 분리 |

## 분리 단위

### 1. 탭 콘텐츠 → 별도 컴포넌트

모달/페이지에 Tabs가 있으면 각 탭의 `children`을 별도 파일로 분리한다.

```
features/school/ui/
├── teacher-detail-modal.tsx          (모달 쉘 + 탭 조립)
├── teacher-basic-info-tab.tsx        (기본 정보 탭)
├── teacher-resume-tab.tsx            (강사 이력서 탭)
└── teacher-teaching-history-tab.tsx  (프로그램 강의 이력 탭)
```

### 2. 헬퍼 함수 → 사용하는 컴포넌트에 포함

포맷팅·계산 등 헬퍼 함수는 해당 탭 컴포넌트 파일 상단에 둔다.
여러 컴포넌트가 공유하면 `lib/` 또는 `utils/`로 분리한다.

### 3. 상태 로직 → 컴포넌트 내부 또는 Hook

- 해당 탭에서만 쓰는 상태(드롭다운 변경 등)는 탭 컴포넌트 내부에 캡슐화한다.
- 복잡한 비즈니스 로직은 `hooks/use-*.ts`로 분리한다.

## 분리 시 규칙

1. **메인 컴포넌트는 조립만 담당** — Props 전달 + 조건부 렌더링만 수행
2. **CSS는 공유** — 탭 컴포넌트들이 같은 CSS 파일의 클래스를 사용해도 무방
3. **네이밍** — 탭 분리 시 `{부모}-{탭이름}-tab.tsx` 형식 사용
4. **Props 최소화** — 분리된 컴포넌트에는 필요한 데이터만 전달 (부모 상태 전체 전달 금지)
5. **export** — 탭 컴포넌트는 named export, 메인 모달/페이지도 named export 유지

## 분리하지 않는 경우

- 단일 테이블 + 필터만 있는 단순한 페이지
- JSX가 짧고 상태가 1~2개뿐인 모달
- 분리하면 오히려 파일 간 의존성이 복잡해지는 경우
