## 1. 노출 방식

- **트리거**: 헤더의 알림 버튼(벨 아이콘) 클릭
- **표시 형태**: **드롭다운(Dropdown)** — 모달(Modal) 사용 금지
- **위치**: 알림 버튼 기준 하단 정렬(예: `placement="bottomRight"`), 버튼 아래에 패널이 붙어서 노출

## 3. 헤더 영역 (카테고리 필터)

- **높이**: 63px (고정)
- **역할**: 카테고리 필터 버튼 6개 가로 배치

### 카테고리 라벨 (순서 고정)

1. **전체**
2. **신청·매칭**
3. **정산**
4. **문의**
5. **업데이트**
6. **시스템**

### 버튼 스타일

- **선택됨(활성)**: 청록색 계열 배경(#00C4C4 등), 흰색 텍스트, 모서리 둥글게
- **선택 안 됨(비활성)**: 연한 회색 배경, 어두운 회색 텍스트, 모서리 둥글게
- 버튼 간 적절한 간격 유지

### 카테고리 ↔ 데이터 매핑 (참고)

- **전체**: 필터 없음
- **신청·매칭**: `type === 'matching'`
- **정산**: `type === 'settlement'`
- **문의**: 추후 API 확장 시 대비 (현재 타입에 없으면 빈 목록 또는 별도 필드 연동)
- **업데이트**: `type === 'schedule'` 또는 추후 `update` 타입
- **시스템**: `type === 'system'`

※ 현재 `NotificationType`은 `schedule | matching | settlement | system` — 문의/업데이트는 UI만 두고, 백엔드 연동 시 확장 가능하도록 구현하면 됨.

---

## 4. 바디 영역 (알림 목록)

- **헤더와 바디 간격**: 16px
- **내용**: 선택된 카테고리에 해당하는 알림 목록 세로 나열
- **스크롤**: 목록이 길면 바디 영역만 세로 스크롤 (드롭다운 높이 500px 유지)

### 개별 알림 카드(항목)

- **형태**: 카드 형태, 모서리 둥글게(6px), 배경 #FAFAFA
- **구성 요소 (위→아래)**  
  1. **카테고리 태그**: `[신청·매칭]`, `[업데이트]` 등 — 대괄호 + 청록색 텍스트  
  2. **주요 알림 문구**: 어두운 회색 텍스트 (예: "신규 참여 신청자가 있습니다.")  
  3. **관련 정보(선택)**: 프로그램/이벤트명 등 — 주 문구보다 연한 회색, 한 줄  
  4. **날짜**: 연한 회색, 형식 예: `YYYY.MM.DD` (예: 2026.01.15)
- 알림 카드 간 세로 간격 유지

---

## 5. 기타 동작

- **바깥 클릭 / 포커스 아웃**: 드롭다운 닫기
- **알림 클릭**: 기존과 동일 — 읽음 처리 + `link` 있으면 해당 경로로 이동 후 드롭다운 닫기
- **모두 읽음**: 헤더 또는 푸터에 "모두 읽음" 노출 시 기존 `markAllAsRead` 동작 유지 (디자인 시안에 있으면 해당 위치에 배치)
