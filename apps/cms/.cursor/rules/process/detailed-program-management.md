# 세부 프로그램 관리

## 삭제 정책

- 프로그램·실적·신청서 등 **다른 도메인에서 참조 중인 세부 프로그램**(`inUse` / 서버 동등 플래그)은 **삭제 불가**.
- 일괄 삭제 시 선택 항목 중 참조 중인 것은 **제외**하고, 사용자에게 **제외 사실을 명시**한다. 전부 참조 중이면 삭제 확인으로 가지 않고 **삭제 불가 안내**만 노출한다.
- API 연동 시 서버가 409 등으로 거절할 수 있으므로, 클라이언트 사전 검증과 함께 **에러 메시지 매핑**을 둔다.

## 인라인 편집

- 편집 모드에서는 **현재 조회 결과(`tableData`) 전 행**에 대해 이름·사용 여부만 수정 가능하도록 한다.
- 조회는 편집 중 혼선을 막기 위해 **저장 완료 전에는 막거나** 동일한 가드 문구로 안내한다.
- **항목 삭제**는 편집 모드에서도 선택 후 허용할 수 있다. 삭제 실행 시 `draftById`·`selectedRowKeys`에서 제거된 행 id를 함께 정리한다.
