# 회원관리 > 전체 회원 — 회원 상세 모달 스펙 (스크린샷 기준)

회원 테이블 **행 클릭 시** 노출되는 회원 상세 UI입니다. 개발 시 **스크린샷**을 상세 참고하여 아래 스펙대로 구현합니다.

---

## 모달 내 영역 (스크린샷 상세 — 개발자 위임용)

스크린샷 기준으로 모달을 **영역별**로 나누어 구현합니다.

| 영역 | 위치 | 구성 요소 |
|------|------|------------|
| **1. 헤더** | 최상단 전체 폭 | teal 배경, 좌측 "회원 상세 정보" 제목(흰색), 우측 X 닫기 버튼(흰색) |
| **2. 권한 문구 + 액션** | 탭 바로 위, 가로 한 줄 | 좌: "회원 본인 및 관리자만 작성/수정이 가능합니다." (회색 소형 글자) / 우: **탈퇴**(빨간 테두리), **수정**(teal 테두리) 버튼, `space-between` |
| **3. 탭** | 권한 문구 아래 | 기본 정보 \| 프로그램 수강 이력 (n) \| 봉사 프로그램 참여 이력 (n). 활성 탭은 teal 밑줄. |
| **4. 기본 정보 본문** | 탭 패널 내부 | **왼쪽: 프로필 사진 영역** / **오른쪽: 회원 정보 테이블**(2열 키-값). 두 영역 가로 배치. |
| **5. 푸터** | 모달 최하단 | "닫기" 버튼 1개, 가로 중앙 정렬, 연한 파란 테두리·흰 배경 |

- **프로필 사진 영역**과 **테이블 필드**는 아래 5절·6절에서 상세 정의.

---

## 1. 모달 치수 및 구조

| 항목 | 값 | 비고 |
|------|-----|------|
| 모달 width | 1400px | 기본값 |
| 바디 높이 | 458px | 헤더 제외, 하단 "닫기" 버튼 영역 포함 |
| 헤더 | "회원 상세 정보", teal 배경, 우측 X 닫기 | |

- 본문 패딩: 스크린샷 기준 좌우 약 20~30px, 상하 여백 일관 적용.

## 2. 권한

- **회원 본인 및 관리자만** 회원정보에 대한 **작성/수정** 가능.
- UI: "회원 본인 및 관리자만 작성/수정이 가능합니다." 문구 노출. 해당 권한이 있을 때만 **수정**·**탈퇴** 버튼 활성화.

## 3. 탭 구성

| 탭 키 | 라벨 |
|-------|------|
| basic | 기본 정보 |
| programs | 프로그램 수강 이력 |
| volunteer | 봉사 프로그램 참여 이력 |

- 기존 "프로그램 이력", "참여 이력" 라벨을 위와 같이 정확히 매칭.

## 4. 기본 정보 탭 레이아웃

### 4.1 상단 한 줄

- **왼쪽**: "회원 본인 및 관리자만 작성/수정이 가능합니다." 문구.
- **오른쪽**: **탈퇴**, **수정** 버튼.
- 레이아웃: `justify-content: space-between` (동일 레벨).

### 4.2 버튼 치수 및 스타일

- **치수**: 100×32px (공통).
- **탈퇴**: 빨간 테두리·빨간 글자 (danger).
- **수정**: teal 테두리·teal 글자 (primary).

## 5. 프로필 사진 영역 (중점)

- **위치**: 기본 정보 탭 본문 **왼쪽**. 프로필 사진과 회원 정보 테이블은 **가로로 나란히** 배치.
- **치수**: **184.5 × 240px** (고정). 세로가 더 긴 직사각형(증명사진 비율).
- **위쪽 문구**: 프로필 영역 상단에 "회원 본인 및 관리자만 작성/수정이 가능합니다." 문구를 둘 수 있음(또는 2영역과 통합). 스크린샷에 따라 프로필 바로 위 작은 글씨로 배치.
- **이미지**: placeholder 또는 `User` 프로필 이미지 URL 필드 연동. 타입에 없으면 추후 확장. 없을 때는 회색 placeholder 영역 + "사진 없음" 등 표시.
- **스타일**: 연한 회색 테두리·모서리 둥글게 처리 권장. `object-fit: cover`로 비율 유지.

## 6. 기본 정보 테이블 (키-값) — 중점

- **위치**: 프로필 사진 **오른쪽**. 프로필과 같은 높이 구간에 2열 키-값 테이블. 연한 회색 가로·세로 구분선.
- **행(tr) 기본 치수**: **키 열 너비 180px, 행 높이 48px**. 성명은 **2행을 차지**하고, 그 **오른쪽**에 한글/영문 **하위 라벨+값**이 위치.
- **테이블 구조**: 좌측 — 성명(2행 병합) | 한글/영문(각 1행) | 연락처 | 주소 | 연동된 소셜 계정. 우측 — 생년월일 | 성별 | 이메일 | 소속 | 가입일.

### 6.1 필드 및 배치 (스크린샷 상세)

**테이블 좌측**

| 키(라벨) | 값/하위 | 비고 |
|----------|---------|------|
| 성명 | **[한글]** `최틴토` + 초록 pill "일정 변경&취소 이력 1회" / **[영문]** `Choi Tinto` | 2영역 차지. 오른쪽에 한글·영문 각 1행. |
| 연락처 | `010-0000-0000` | `User.phone` |
| 주소 | `서울특별시 강서구 화곡동` | `schoolInfo.address` 또는 `detailAddress` 등 |
| 연동된 소셜 계정 | `카카오` \| `구글` | `User.socialAccounts` |

**테이블 우측**

| 키(라벨) | 값 표현 | 비고 |
|----------|---------|------|
| 생년월일 | `2010.09.15` \| `만 15세` | `User.birthDate` |
| 성별 | `여성` \| `해당 없음` | `User.gender` |
| 이메일 | `tinto@naver.com` | `User.email` |
| 소속 | `틴토고등학교` \| `1학년` | `User.affiliation` 또는 `schoolInfo` |
| 가입일 | `2025.09.15` | `User.createdAt` |

- **권한/관리자용**: 관리자일 때만 — 권한(태그), 관리자 구분, 프로그램 범위, 상태. tr 높이 48px·키 180px 동일.
- **값 구분자**: `|`(세로선)으로 복수 값 표기 시 구분(예: 생년월일 \| 만 15세, 소속 \| 학년).
- 현재 `User` 타입에는 `name`, `email`, `phone`, `createdAt`, `schoolInfo` 등만 있음. **한글/영문 성명, 생년월일, 성별, 소속, 연동 소셜** 등은 스펙 위치에 맞춰 placeholder 또는 확장 필드로 표시.

## 7. 하단 버튼

- **닫기**: 한 개, 가로 중앙 정렬. 연한 파란 테두리·파란 글자. 클릭 시 모달 닫기.

## 9. 구현 시 참고 사항 (개발자 노트)

- **Drawer vs Modal**: 스크린샷은 중앙 모달 형태. 1400px 고정 폭·458px 바디 높이를 맞추려면 Ant Design **Modal** 전환 또는 Drawer width/height 고정이 필요. 스펙은 "모달" 기준이며, Drawer 유지 시 동일 치수·레이아웃 적용.
- **데이터 필드**: 성명(한글/영문), 생년월일, 성별, 소속, 연동 소셜은 현재 `User`에 없을 수 있음. 스펙에 정의된 위치에 맞춰 placeholder 또는 확장 필드로 표시.
- **탈퇴**: 100×32 탈퇴 버튼 클릭 시 기존 회원 삭제(DeleteGuideModal) 플로우와 연동할지, 별도 "탈퇴" 플로우로 할지는 기획 확인 후 구현.
