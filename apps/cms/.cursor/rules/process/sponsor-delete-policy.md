# 후원사 삭제 정책

후원사 삭제 시 아래 정책을 반드시 지킨다.

- 현재 진행 중인 프로그램을 후원 중인 후원사는 **삭제 불가**.
- 삭제 버튼 클릭 시 진행 중 프로그램이 1건 이상이면 삭제 확인 모달이 아니라 **삭제 불가 안내 팝업**을 먼저 노출한다.
- 안내 문구는 다음 의미를 유지한다.
  - 현재 진행중인 프로그램이 있습니다.
  - 후원사를 삭제하려면 진행중인 프로그램을 삭제하거나 후원사를 제외해주세요.
- 진행 중 프로그램이 없는 경우에만 삭제 확인(최종 확인 입력 포함) 단계로 진입한다.
- 삭제 실행 시 후원사와 연관된 기본/연락처/매핑 정보는 삭제 대상에 포함한다.
- 단, 정산·통계·성과 집계 등 실적 관련 값은 삭제하지 않고 유지한다.
- API 연동 시에도 동일 정책을 적용하며, 물리 삭제/소프트 삭제 구현 여부와 무관하게 실적 값 보존을 보장한다.
