# Development process

## Phases (typical order)

1. **Planning** — requirements, specs, user scenarios.  
2. **Design** — UX/UI, Ant Design usage, design system.  
3. **Build** — technical plan, implementation, code review.  
4. **Verify** — acceptance with PM, scenario tests, fixes.

## Responsibilities

- **Developers** — architecture, review, performance.  
- **Designers** — design system, UX quality.  
- **Planners** — requirements, business rules.  
- **PM** — schedule, priorities, decisions.

## Workflow

Plan → align across roles → implement & test → review → next phase.
