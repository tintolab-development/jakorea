# 개발 프로세스

## Phase별 개발 프로세스

각 Phase는 다음 순서로 진행됩니다:

### 1. 기획 단계

- 시니어 기획자와 요구사항 정의
- 기능 명세서 작성
- 사용자 시나리오 정의

### 2. 디자인 단계

- 시니어 UX/UI 디자이너와 디자인 검토
- Ant Design 컴포넌트 활용 방안 논의
- 디자인 시스템 확정

### 3. 개발 단계

- 시니어 개발자와 기술 검토
- 구현 계획 수립
- 코드 리뷰 및 피드백

### 4. 검증 단계

- PM과 함께 기능 검증
- 사용자 시나리오 테스트
- 버그 수정 및 개선

## 역할별 책임

- **시니어 개발자**: 기술 아키텍처, 코드 리뷰, 성능 최적화
- **시니어 UX/UI 디자이너**: 디자인 시스템, 사용자 경험 개선
- **시니어 기획자**: 요구사항 정의, 비즈니스 로직 검증
- **PM**: 일정 관리, 우선순위 결정, 의사결정

## 개발 워크플로우

1. Phase별 작업 계획 수립
2. 기획/디자인/개발 단계별 소통
3. 기능 구현 및 테스트
4. 코드 리뷰 및 개선
5. 다음 Phase로 진행
