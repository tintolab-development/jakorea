# 수강 프로그램 상세 모달 — 게시글 탭 UI 스펙 (디자이너 → 개발자 위임)

수강 프로그램 상세 모달에서 **「게시글」 탭** 선택 시 노출되는 본문 UI입니다.  
모달 헤더를 제외한 **바디 영역**과 **게시글 / 파일 및 사진** 2컬럼 레이아웃·태그·버튼 스펙을 상세 정의합니다. 구현 시 **스크린샷**과 본 문서를 기준으로 적용합니다.

---

## 1. 모달 치수 및 구조 (공통)

| 항목 | 값 | 비고 |
|------|-----|------|
| 모달 width | 1400px | 기존 TealHeaderModal large 기준 |
| **바디 높이** | **814px** | **헤더 제외** (탭·본문·푸터 상단까지) |
| 헤더 | "수강 프로그램 상세", teal 배경, 우측 X 닫기 | |
| 탭 | 프로그램 상세 정보 \| **게시글** \| 제출 내역 및 서류 발급 | 활성 탭 teal 밑줄 |
| 푸터 | "닫기" 버튼 1개, 중앙 정렬 | |

- 본문(탭 패널) 패딩: 스크린샷 기준 적용. 바디는 `min-height: 0`, `height: 100%`로 탭 콘텐츠가 814px 영역을 채우도록 구성.

---

## 2. 게시글 탭 본문 — 2컬럼 레이아웃

게시글 탭 선택 시 본문은 **2개의 컬럼**으로 구분합니다.

| 컬럼 | 위치 | 역할 |
|------|------|------|
| **왼쪽** | 본문 좌측 | **게시글** — 제목 + "게시글 작성" 버튼, 게시글 목록 |
| **오른쪽** | 본문 우측 | **파일 및 사진** — 제목 + "더보기" 버튼, 파일·사진 목록 |

- 컬럼 비율: 스크린샷 기준 왼쪽이 게시글 목록, 오른쪽이 파일 목록. 구분선 또는 gap으로 시각적 분리.
- 각 컬럼 내부는 필요 시 스크롤 가능(본문 전체 높이 814px 내에서).

---

## 3. 왼쪽 컬럼 — 게시글

### 3.1 상단 한 줄 (타이틀 + 버튼)

- **왼쪽**: 섹션 타이틀 **「게시글」** (기존 모달 section-title 스타일: 16px, bold, 라벨 컬러).
- **오른쪽**: **「게시글 작성」** 버튼.
- 레이아웃: 타이틀과 버튼 **같은 레벨**에 배치 (`flex`, `justify-content: space-between` 또는 동일 효과).
- **버튼 치수**: **100 × 32px** (고정).
- **버튼 스타일**: 민트(teal) 채움 — `AppButton` `variant="primary"` 또는 동일 스타일.

### 3.2 게시글 목록 — 카드/아이템

각 게시글 아이템 구성 (스크린샷 기준):

- **프로필 영역**: 왼쪽 — 회색 배경 아바타 + 작성자 이름(예: "박○○ 담당교사님", "김틴토 강사님", "JA KOREA 알림"). 그 아래 작성일시(예: "2026년 1월 15일 오후 3:00").
- **내용**: 작성자 아래 게시글 본문. 길면 "...더보기" 링크.
- **태그**: 내용 영역 **오른쪽 상단** — 읽음/읽지 않음 상태 태그 (아래 4절 참고).
- **하단 메타**: 조회수(눈 아이콘), 댓글 수(말풍선 아이콘), 첨부 파일 수(아이콘). 예: "2개의 첨부파일" 텍스트.

### 3.3 읽지 않은 게시글 강조

- **읽지 않은 게시글**은 **민트 스트로크(테두리)** 로 시각적 구분 (예: `border-left: 3px solid` teal 또는 카드 전체 연한 teal 테두리).
- 동시에 **「읽지 않음」** 태그 노출 (4.1절 스타일).

---

## 4. 읽음 / 읽지 않음 태그 스타일 (필수 적용)

태그는 **둥근 pill** 형태. 개발 시 아래 CSS를 그대로 적용합니다.

### 4.1 읽지 않음 태그

- **라벨**: "읽지 않음".
- **CSS**:
  - `display: flex`
  - `padding: 3px 8px`
  - `justify-content: center`
  - `align-items: center`
  - `gap: 10px`
  - `border-radius: 50px`
  - `background: rgba(1, 161, 175, 0.10)` (민트 10% 투명)
- 글자색: 진한 회색(가독성 유지). 테두리는 없음 또는 동일 민트 연하게.

### 4.2 읽음 태그

- **라벨**: "읽음".
- **CSS**:
  - `border-radius: 50px`
  - `background: rgba(51, 51, 51, 0.10)` (회색 10% 투명)
- 패딩·정렬: 읽지 않음과 동일하게 `padding: 3px 8px`, `display: flex`, `align-items: center`, `justify-content: center` 권장.
- 글자색: 진한 회색.

---

## 5. 오른쪽 컬럼 — 파일 및 사진

### 5.1 상단 한 줄 (타이틀 + 버튼)

- **왼쪽**: 섹션 타이틀 **「파일 및 사진」** (동일 section-title 스타일).
- **오른쪽**: **「더보기」** 버튼.
- 레이아웃: 타이틀과 버튼 **같은 레벨**.
- **버튼 치수**: **100 × 32px** (고정).
- **버튼 스타일**: 흰 배경 + 민트(teal) 테두리 — `AppButton` `variant="cancel"` 또는 아웃라인 스타일.

### 5.2 파일 목록

- 파일 유형별 아이콘(원형 또는 사각, 예: PDF 빨간, XLS 녹색 등) + **파일 이름**.
- 파일 이름 아래 **「원글 보기」** 링크.
- 목록이 길면 세로 스크롤 (오른쪽 컬럼 내부).

## 8. 구현 시 참고 사항 (개발자 노트)

- **데이터**: 게시글·파일 목록은 초기 mock 또는 기존 API 구조에 맞춰 연동. 읽음/읽지 않음은 게시글 단위 boolean 또는 상태 필드로 제어.
- **접근성**: 태그에 `aria-label` 또는 텍스트 노출로 "읽음"/"읽지 않음" 상태 전달.
- **반응형**: 현재 스펙은 1400px 모달 기준. 작은 뷰포트에서는 2컬럼을 세로 쌓기 등 별도 정의 가능.
