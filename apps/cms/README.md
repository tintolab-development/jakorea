# CMS

JAKorea CMS 프로젝트입니다.

## 시작하기

개발 서버 실행:

```bash
pnpm --filter cms dev
```

빌드:

```bash
pnpm --filter cms build
```

타입 체크:

```bash
pnpm --filter cms typecheck
```

린트:

```bash
pnpm --filter cms lint
```
