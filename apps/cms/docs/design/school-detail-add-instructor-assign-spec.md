# 학교 상세정보 – 강사진 추가 배정 모달 명세 (개발 위임)

**대상**: 프로그램 상세 > 프로그램 진행현황 > 참여 학교 정보 탭 > 학교 상세 정보 모달  
**역할**: 기획·디자이너·PM 디테일 확인 후 개발자 위임용  
**참조**: [persona.md](../../.cursor/rules/process/persona.md), [school-detail-modal-spec.md](./school-detail-modal-spec.md)

---

## 1. 요구사항 요약

- **트리거**: 학교 상세정보 모달 > 기본 정보 탭 > 강사진 정보 섹션에서 **「추가 배정」** 버튼 클릭 시
- **동작**: **강사진 추가 배정** 모달이 노출되어, **기존에 존재하는 강사 목록에서** 강사를 선택하고, 해당 학교에 배정할 때 역할(대표 강사 / 일반 강사)을 지정한 뒤 추가할 수 있어야 함.

---

## 2. 사용자 시나리오 (기획)

| 단계 | 사용자 행동                                              | 시스템 동작                                                                                                                       |
| ---- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 학교 상세 모달에서 강사진 정보 영역의 「추가 배정」 클릭 | 강사진 추가 배정 모달이 열림                                                                                                      |
| 2    | 강사명 필드에서 기존 강사 1명 선택                       | 선택 가능한 목록은 시스템에 등록된(또는 프로그램 참여) 강사 풀. 이미 이 학교에 배정된 강사는 목록에서 제외 권장(정책에 따라 구현) |
| 3    | 대표 강사 지정에서 「대표 강사」 또는 「일반 강사」 선택 | 기본값: 일반 강사                                                                                                                 |
| 4    | 「추가」 클릭                                            | 선택한 강사가 해당 학교 강사진 목록에 추가됨. 모달 닫힘. 학교 상세 강사진 테이블에 반영                                           |
| 5    | 「취소」 클릭 또는 X / 마스크 클릭                       | 모달만 닫힘, 변경 없음                                                                                                            |

**예외**

- 강사명 미선택 시 「추가」 클릭 → 필수 선택 검증 메시지 표시 (예: "배정할 강사를 선택해 주세요").
- 역할은 미선택 시 기본값(일반 강사) 적용.

## 3. UI/디자인 스펙 (디자이너)

### 3.1 모달 공통

| 항목     | 값                            | 비고                                                                         |
| -------- | ----------------------------- | ---------------------------------------------------------------------------- |
| 컴포넌트 | `TealHeaderModal`             | 기존 공용 모달 재사용                                                        |
| 제목     | **강사진 추가 배정**          | 헤더 청록 배경, 흰색 텍스트                                                  |
| 닫기     | 헤더 우측 X + 마스크 클릭     | 기존 TealHeaderModal 동작                                                    |
| 푸터     | 취소(보조) / 추가(주요, 청록) | 버튼 스타일: 기존 `AppButton` variant="cancel" / variant="primary" modalTeal |

### 3.2 본문 필드

| 필드(레이블)       | 컨트롤                        | 필수            | placeholder / 옵션                                   |
| ------------------ | ----------------------------- | --------------- | ---------------------------------------------------- |
| **강사명**         | Select (단일 선택, 검색 가능) | O               | placeholder: "배정할 강사를 선택해 주세요"           |
| **대표 강사 지정** | Radio.Group                   | O (기본값 있음) | 옵션: "대표 강사" / "일반 강사", 기본값: "일반 강사" |

- 강사명 Select: 기존 강사 목록을 옵션으로 표시. `showSearch`, `optionFilterProp="label"` 등으로 검색 가능 권장.
- 레이아웃: 강사명 한 행, 대표 강사 지정 한 행. 기존 add-instructor-modal 레이아웃·간격 참고.

### 3.3 시안 기준

- 제공된 시안(강사진 추가 배정 모달) 기준으로 레이블·placeholder·라디오 문구 일치.
- 강사명 필드 우측 셀렉트 아이콘(쉐브론)으로 드롭다운 표시.

## 4. 데이터·로직 (개발자 참고)

### 4.1 기존 강사 목록

- **선택 가능한 강사 풀**: 시스템(또는 해당 프로그램)에 등록된 강사 목록 사용.
  - 1차 구현: Mock 기준으로 **참여 강사진 목록**(예: `MOCK_PARTICIPATING_INSTRUCTORS` 또는 동일 프로그램·학교 풀)에서 옵션 생성.
  - **이미 해당 학교에 배정된 강사**는 선택 목록에서 제외하는 것을 권장(중복 배정 방지). 제외 기준: `detail.instructors`의 `id`(또는 식별자)와 매칭.
- Select 옵션: 최소 `{ label: 강사명, value: 강사 id }`. 필요 시 연락처·이메일 등은 옵션 서브라벨 또는 검색용으로만 사용.

### 4.2 폼 제출 시

- 선택한 강사 id + 역할(lead | assistant)을 부모로 전달.
- 부모(SchoolDetailModal)에서:
  - 해당 강사의 상세 정보(이름, 연락처, 이메일)를 mock/API로 조회해 `SchoolDetailInstructorRow` 형태로 만든 뒤,
  - 기존 `detail.instructors`에 1건 추가하고 `onSaveInstructorInfo(schoolId, newInstructors)` 호출하거나, 수정 모드라면 instructorForm의 `instructors` 배열에 추가 후 저장 시 `onSaveInstructorInfo` 호출.

### 4.3 타입

- 역할: 기존 `InstructorRoleKey` ('lead' | 'assistant') 및 `INSTRUCTOR_ROLE_LABELS` 사용.
- 새로 배정된 행의 `id`는 mock 시 임의 생성(예: `assign-${Date.now()}` 또는 기존 참여 강사 id 재사용). 정산 현황 등은 mock 기본값 적용.

## 5. 개발 작업 체크리스트

- [ ] 학교 상세 모달에서 「추가 배정」 버튼에 `onClick` 연결 → 강사진 추가 배정 모달 `open` 상태로 전환.
- [ ] **강사진 추가 배정** 전용 모달 컴포넌트 추가 (또는 기존 모달 확장).
  - TealHeaderModal, 제목 "강사진 추가 배정", 푸터 취소/추가.
  - 강사명: Select(기존 강사 목록, 검색 가능), placeholder "배정할 강사를 선택해 주세요".
  - 대표 강사 지정: Radio "대표 강사" / "일반 강사", 기본 "일반 강사".
- [ ] 기존 강사 목록: 참여 강사진 mock에서 옵션 생성, 이미 해당 학교에 배정된 강사 id 제외.
- [ ] 추가 클릭 시: 선택 강사 + 역할을 학교 강사진에 반영, 모달 닫기, (수정 모드면 폼 반영 후 저장 시점에 onSaveInstructorInfo 호출 또는 즉시 onSaveInstructorInfo 호출).
- [ ] 취소/닫기: 모달만 닫기.

---

## 6. 검증 기준 (Acceptance)

- 학교 상세 모달 > 기본 정보 탭에서 「추가 배정」 클릭 시 **강사진 추가 배정** 모달이 노출된다.
- 강사명 필드에서 **기존에 존재하는 강사 목록**이 선택 가능하다(검색 가능 권장).
- 대표 강사 지정 라디오로 대표 강사/일반 강사를 선택할 수 있고, 기본값은 일반 강사이다.
- 「추가」 클릭 시 선택한 강사가 해당 학교 강사진 테이블에 1건 추가되고 모달이 닫힌다.
- 「취소」 또는 X/마스크 클릭 시 모달만 닫히고 변경 사항은 반영되지 않는다.
- 강사명 미선택 시 「추가」 클릭하면 검증 메시지가 표시된다.
