# 강의 출석 내역 모달 명세 (디자이너/기획/PM → 개발 위임)

**대상**: 수강 신청 학교 상세 정보 모달(또는 학교 상세 정보 모달) > **학생 명단** 탭  
**트리거**: 학생 명단 테이블에서 **「강의 출석 내역」** 열의 링크/버튼(예: "0/4") 클릭 시  
**참조 시안**: 강의 출석 내역 모달 스크린샷(학생명·참석률 상단, 회차별 출석 테이블, 닫기 버튼)  
**관련 명세**: [school-detail-modal-spec.md](./school-detail-modal-spec.md), [school-detail-modal-student-list-edit-spec.md](./school-detail-modal-student-list-edit-spec.md)

---

## 1. 개요 (PM/기획)

- **트리거**: 학교 상세 모달 > 학생 명단 탭 > **강의 출석 내역** 열의 텍스트/링크(예: "1/4") 클릭 시 1차 모달 오픈.
- **모달 제목**: 「강의 출석 내역」
- **목적**: 해당 학생의 강의별 출석 요약(참석률) 및 **회차별 출석 상태**를 보고, 필요 시 **각 회차 셀 클릭으로 상세 모달**을 연다.
- **테이블 헤더 순서**: 반드시 명세 순서를 준수한다. 회차 수는 프로그램/학교마다 다르므로 **동적 컬럼**으로 구현한다.

---

## 2. 1차 모달: 강의 출석 내역 (디자이너 → 개발)

### 2.1 공통

- **컨테이너**: `TealHeaderModal` 재사용. 제목 "강의 출석 내역", 헤더 우측 X 닫기, 마스크 클릭 시 닫힘.
- **푸터**: **닫기** 버튼 1개, 가운데 정렬, 기존 스타일(밝은 청록 테두리, 120×40 권장).

### 2.2 상단 정보 (헤더 순서 고정)

**표시 형태**: 2열 키-값 영역. **순서는 아래와 동일하게 유지한다.**

| 순서 | 라벨(필드명) | 표시 내용                    | 비고                                                                                               |
| ---- | ------------ | ---------------------------- | -------------------------------------------------------------------------------------------------- |
| 1    | 학생명       | 해당 학생 이름 (예: 김ㅇㅇ)  |                                                                                                    |
| 2    | 참석률       | "{N}% (강의 진행 회차 기준)" | N = (출석 완료한 회차 수 / 강의 진행된 회차 수)×100, 정수. "강의 미진행" 회차는 분모·분자에서 제외 |

- **레이아웃**: Descriptions 또는 2열 테이블. **왼쪽 셀 = 학생명 라벨, 오른쪽 셀 = 학생명 값** / 다음 행 또는 같은 행 오른쪽에 **참석률 라벨 | 참석률 값**. 시안 기준으로 학생명·참석률이 상단에 한 블록으로 배치.

### 2.3 회차별 출석 내역 테이블 (헤더 순서·가변 회차)

- **테이블 역할**: 회차별로 "출석 완료", "결석", "강의 미진행" 등 **한 행에 회차 수만큼 셀**을 나열.
- **헤더 순서**: **1회차 → 2회차 → 3회차 → … → N회차** 순서를 **정확히** 유지. 회차 수 N은 **프로그램/학교/강의마다 다를 수 있음** (동적 컬럼).
- **헤더 라벨**: `1회차`, `2회차`, … `N회차` (숫자 + "회차").
- **본문 셀 값 예시**:
  - 출석 완료
  - 결석
  - 강의 미진행
  - (추가 상태는 기획 확정 시 동일 패턴으로 확장)
- **각 셀(텍스트 영역) 클릭 시**: **2차 모달** 노출 (아래 §3 참고). 클릭 가능한 영역은 **텍스트가 들어 있는 셀 전체**로 하여, 사용자가 셀을 클릭하면 해당 회차 상세 모달이 열리도록 한다.
- **UI 요구**: 셀이 클릭 가능함을 알 수 있도록 커서(pointer) 및 필요 시 호버 스타일 적용. 테이블 셀 경계선 명확, 회차 라벨(1회차, 2회차 등)은 굵은 글씨로 강조 가능.

### 2.4 테이블 UI 디테일 (디자이너)

- 테이블: Ant Design Table 또는 동일 스타일. 헤더 배경 `#fafafa`, 셀 구분선, 세로 중앙 정렬.
- 회차 수가 많을 경우: 가로 스크롤 또는 모달 가로 폭 내에서 컬럼 비율 조정. **헤더 순서(1회차, 2회차, …)는 절대 바꾸지 않는다.**

---

## 3. 2차 모달: 회차별 출석 셀 클릭 시 상세 (기획/디자이너 → 개발)

- **트리거**: §2.3 회차별 출석 테이블에서 **특정 회차 셀(텍스트 영역)** 클릭 시.
- **목적**: 해당 회차의 출석 상세(사유, 일시, 메모, 변경 이력 등)를 보여주는 모달. 기획 확정 전까지는 **모달 프레임만 구현하고, 본문은 플레이스홀더(예: "해당 회차 출석 상세 (추가 기획 확정 예정)")** 로 두어도 됨.
- **모달 제목 예시**: 「N회차 출석 상세」 또는 「출석 상세」.
- **푸터**: 닫기 버튼 1개.
- **데이터**: 클릭한 학생 ID + 회차 번호(또는 회차 ID)를 전달하여, 추후 API 연동 시 해당 회차 출석 상세 조회에 사용.

---

## 4. 데이터·타입 (기획 → 개발)

### 4.1 1차 모달 입력

- **트리거 시 전달**: 학교 ID(또는 프로그램·학교 식별자), **학생 ID**(또는 `SchoolDetailStudentRow` 한 행).
- **표시용 데이터 제안**:
  - `studentName: string` — 학생명
  - `attendanceRatePercent: number` — 참석률 (0–100, 정수)
  - `sessions: Array<{ roundNumber: number; status: 'attended' | 'absent' | 'not_held' | string }>` — 회차 순서대로. `roundNumber`는 1부터 N. `status` 표시 문구: attended → "출석 완료", absent → "결석", not_held → "강의 미진행". (값은 기획 확정 시 enum으로 고정)
- **회차 수**: `sessions.length`에 따라 **동적 컬럼** 생성. 헤더는 항상 1회차, 2회차, … N회차 순서.

### 4.2 2차 모달 입력

- **클릭 시 전달**: 학생 ID, 회차 번호(또는 회차 ID).
- **1차 구현**: 모달만 노출, 본문 플레이스홀더. 추후 상세 API 연동.

### 4.3 Mock

- 1차 모달: `SchoolDetailStudentRow`의 `lectureAttendance`(예: "1/4")와 별도로, 출석 상세 목업(학생명, 참석률, 회차별 status 배열) 준비. 회차 수 3~6개 등 가변으로 테스트 가능하게.
- 2차 모달: 클릭 시 받은 학생 ID + 회차만 state에 저장하고, 본문은 안내 문구만 표시.

---

## 5. 수정 모드 시 동작 (기획)

- **학생 명단 탭이 수정 모드일 때**: 기존 [school-detail-modal-student-list-edit-spec.md](./school-detail-modal-student-list-edit-spec.md)에 따라 **강의 출석 내역 링크/버튼은 disabled**. 클릭해도 1차 모달이 열리지 않음.

## 6. 구현 위임 체크리스트 (개발자)

### 6.1 1차 모달 (강의 출석 내역)

- [ ] **모달 컴포넌트**: `LectureAttendanceModal`(가칭) 생성. `TealHeaderModal` 래핑.
- [ ] **상단 정보**: **순서 고정** — (1) 학생명 라벨 | 학생명 값, (2) 참석률 라벨 | 참석률 값. "참석률" 값 형식: "{N}% (강의 진행 회차 기준)".
- [ ] **회차별 테이블**: 헤더 **1회차, 2회차, … N회차** 순서 정확히 유지. N은 `sessions.length`로 동적. 각 셀 값: "출석 완료" / "결석" / "강의 미진행" 등 status 매핑.
- [ ] **셀 클릭**: 각 회차 셀(텍스트 영역) 클릭 시 2차 모달 오픈. 클릭 가능 영역은 셀 전체, `cursor: pointer` 및 호버 스타일 적용.
- [ ] **연동**: 학교 상세 모달 > 학생 명단 > "강의 출석 내역" 열 버튼/링크 클릭 시, 해당 행(학생) 정보를 state에 저장하고 1차 모달 `open` + 데이터 전달. 수정 모드일 때는 클릭 비활성화.
- [ ] **타입·Mock**: §4.1 구조로 타입 정의 및 mock(회차 수 가변) 준비.

### 6.2 2차 모달 (회차 출석 상세)

- [ ] **모달 컴포넌트**: 회차 셀 클릭 시 노출. 제목 "N회차 출석 상세" 또는 "출석 상세". 푸터 닫기 1개.
- [ ] **1차 구현**: 본문은 플레이스홀더 또는 "해당 회차 출석 상세 (추가 기획 확정 예정)" 안내 문구. 전달 인자: 학생 ID + 회차 번호.
- [ ] **연동**: 1차 모달 테이블 셀 클릭 시 선택 학생 ID + 회차 번호 저장 후 2차 모달 open.

### 6.3 테이블 헤더·회차 검증

- [ ] 회차 수가 3, 4, 6 등으로 다른 mock으로 테스트하여 **헤더가 항상 1회차 → 2회차 → … → N회차** 순서인지 확인.
- [ ] 상단 블록 **학생명 → 참석률** 순서가 시안과 일치하는지 확인.
