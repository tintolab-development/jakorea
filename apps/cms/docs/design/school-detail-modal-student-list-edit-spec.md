# 학교 상세정보 모달 · 학생 명단 탭 수정 모드 (개발 위임 명세)

**대상**: 프로그램 진행현황 > 참여 학교 정보 탭 > 학교 상세 정보 모달 > **학생 명단** 탭  
**목적**: 학생 명단 탭의 **수정 모드** 진입 시 UI/동작 규칙을 정의하고, 개발 구현에 위임  
**참조**: [학교 상세 정보 모달 명세](./school-detail-modal-spec.md), 스크린샷(학생 명단 탭)  
**폼 관리**: react-hook-form (`useForm`, `useFieldArray`) 사용 권장

---

## 1. 수정 모드 개요

- **진입**: 학생 명단 탭 상단의 **「수정」** 버튼 클릭 시 수정 모드 진입.
- **종료**: **「저장」** 클릭 후 저장 완료 시, 또는 **「닫기」** 시 저장 여부 확인 후 보기 모드로 복귀(또는 모달 닫기).
- **보기 모드**: 현재와 동일하게 테이블은 읽기 전용 텍스트 표시, 수정 버튼만 노출.

---

## 2. 인풋으로 변경되는 영역 (수정 모드)

수정 모드일 때 아래 테이블 컬럼은 **텍스트 표시**가 아닌 **편집 가능한 입력 필드**로 전환한다.

| 컬럼명(레이블) | 데이터 필드  | 입력 타입                 | 비고              |
| -------------- | ------------ | ------------------------- | ----------------- |
| 학생명         | `name`       | `<Input>` 텍스트          | 단일 행           |
| 학급           | `gradeClass` | `<Input>` 또는 `<Select>` | 예: 1반, 3반      |
| 연락처         | `contact`    | `<Input>` 텍스트          | 예: 010-1234-5678 |
| 이메일         | `email`      | `<Input>` 텍스트          |                   |

**변경하지 않는 컬럼 (수정 모드에서도 비입력)**

- **No.**: 순번, 읽기 전용 (표시만).
- **강의 출석 내역**: 링크/텍스트 표시 (보기 모드에서 클릭 시 [강의 출석 내역 모달](./lecture-attendance-modal-spec.md) 노출. 수정 모드에서는 버튼/링크 비활성화, 아래 3절 참고).
- **과제 제출 내역**: 「내역 보기」 버튼 (수정 모드에서는 비활성화, 아래 3절 참고).

---

## 3. 수정 모드에서 비활성화(disabled) 처리할 요소

| 영역          | 요소                              | 수정 모드 시 동작                                                                                                                                               |
| ------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **탭**        | 기본 정보 탭                      | **비활성화** 또는 탭 전환 시 「저장하지 않은 변경이 있습니다. 계속하시겠습니까?」 확인 후 전환. (기획/PM 결정에 따라 탭 비활성화만 할지, 확인 팝업만 할지 선택) |
| **검색/필터** | 학생명 입력 필드                  | **disabled**                                                                                                                                                    |
| **검색/필터** | 학급 드롭다운                     | **disabled**                                                                                                                                                    |
| **검색/필터** | 조회 버튼                         | **disabled**                                                                                                                                                    |
| **우측 상단** | 저장 버튼                         | 변경 사항이 **있을 때만** 활성화, 없으면 **disabled**                                                                                                           |
| **우측 상단** | 학교 등록 버튼                    | 수정 모드에서는 **disabled** 또는 숨김 (기획 확정 시 선택)                                                                                                      |
| **테이블**    | 행 선택 체크박스                  | **disabled** (일괄 선택 비활성화)                                                                                                                               |
| **테이블**    | 강의 출석 내역 링크/버튼          | **disabled** (클릭 불가)                                                                                                                                        |
| **테이블**    | 과제 제출 내역 「내역 보기」 버튼 | **disabled** (클릭 불가)                                                                                                                                        |
| **하단**      | 닫기 버튼                         | 클릭 시 **미저장 변경 있으면** 「저장하지 않은 변경 사항이 있습니다. 계속하시겠습니까?」 확인 후 진행/취소                                                      |

## 4. 폼 관리 (react-hook-form)

- **권장**: `react-hook-form`의 `useForm` + `useFieldArray`로 학생 명단 전체를 하나의 폼으로 관리.
- **필드 배열**: 학생 목록을 `students`(또는 `studentList`) 같은 배열 필드로 두고, 각 항목에 `name`, `gradeClass`, `contact`, `email` 매핑.
- **저장 버튼**: `handleSubmit`으로 제출. 변경 감지는 `formState.isDirty` 또는 `formState.dirtyFields`로 판단하여 저장 버튼 활성/비활성.
- **초기값**: 모달 오픈/탭 전환 시 현재 **필터 적용된 학생 목록**을 폼 `defaultValues`로 넣고, 수정 모드 진입 시 `reset(values)`로 동기화 (기존 `useProgramDetailEditForm` 패턴 참고).
- **검증**: 필요 시 `zod` 스키마로 학생 행 단위 검증 (이메일 형식, 연락처 형식 등) 적용.

**참고 코드**

- `useForm` + `useFieldArray`: `apps/cms/src/features/settlement/ui/instructor-settlement-form.tsx`, `apps/cms/src/features/program/ui/program-form.tsx`
- 수정 모드 + reset 동기화: `apps/cms/src/features/program/hooks/use-program-detail-edit-form.ts`
- Controller 사용: `apps/cms/src/features/program/ui/basic-info-section.tsx`

---

## 5. 데이터·타입

- 학생 행 타입: `SchoolDetailStudentRow` (`id`, `no`, `name`, `gradeClass`, `contact?`, `email?`, …) 유지.
- 폼 값 타입 예: `{ students: Array<{ id: string; name: string; gradeClass: string; contact?: string; email?: string }> }` (필요 시 `no` 제외하고 서버 전송용만 사용).

## 6. 개발 작업 체크리스트

- [ ] 학생 명단 탭에 **보기 모드 / 수정 모드** 상태 추가 (예: `isStudentListEditMode`).
- [ ] 수정 버튼 클릭 시 수정 모드 진입, 이때 `react-hook-form`으로 학생 목록 폼 초기화 (`useFieldArray` 기준).
- [ ] 테이블에서 학생명/학급/연락처/이메일을 수정 모드일 때만 `Controller`/`register`로 입력 컴포넌트 렌더.
- [ ] 3절의 검색·필터, 탭, 저장/학교 등록, 체크박스, 출석/과제 링크·버튼, 닫기 버튼에 대해 수정 모드 시 disabled/확인 로직 적용.
- [ ] 저장 버튼: `formState.isDirty`(또는 dirtyFields)가 true일 때만 enabled.
- [ ] 닫기 시 미저장 변경 있으면 확인 다이얼로그 후 진행/취소.
- [ ] (선택) 탭 전환 시 미저장 변경 확인 또는 기본 정보 탭 비활성화.
