# 강의 신청 강사 상세 정보 모달 명세 (디자이너/기획/PM → 개발 위임)

**대상**: 신청자 목록 > 신청 강사 탭 — 강의 신청 강사 목록 테이블에서 **강사명 열 클릭** 시 노출되는 모달  
**참조 시안**: 제공된 스크린샷 (기본 정보 / 강사 이력서 탭, 강사명 옆 일정 변경&취소 이력 배지, 반려/승인/닫기 버튼)  
**관련 명세**: [program-detail-applicants-tab-spec.md](./program-detail-applicants-tab-spec.md)

---

## 1. 개요 (PM/기획)

- **트리거**: 강의 신청 강사 목록 테이블에서 **강사명** 열(또는 해당 행) 클릭 시 모달 오픈.
- **모달 제목**: 「강의 신청 강사 상세 정보」
- **목적**: 해당 강사의 기본 정보·이력서를 확인하고, 결재(반려/승인) 액션을 수행할 수 있게 한다.

---

## 2. 모달 구조 (디자이너 → 개발)

### 2.1 공통

- **컨테이너**: 기존 `TealHeaderModal` 재사용. 제목 영역(청록 헤더) + 본문 + 푸터(닫기 버튼).
- **본문**: **탭 2개** — 「기본 정보」 | 「강사 이력서」. 탭 전환 시 해당 패널만 표시.

### 2.2 탭: 기본 정보

- **바디 레이아웃**: 좌측 **프로필 사진 영역(258×336)** + 우측 **테이블 영역** 분리. 강사진 추가 모달 기본 정보 구조 참고.
- **프로필 영역**: 이미지 URL 있으면 표시, 없으면 플레이스홀더(아이콘/문구).
- **테이블 구조**: native `<table>`. **성명**은 컬럼 하나를 차지하고 **rowSpan=2**, 옆에 **2개 행**으로 한글(값+배지) / 영문 라벨·값. 그 외 필드는 §5 수정 사항 반영.
- **테이블 필드 순서**: 좌 컬럼 [성명(한글·영문), 연락처, 주소, 최종 학력, 한 줄 소개] / 우 컬럼 [생년월일, 성별 및 병역사항, 이메일, 정산 계좌 정보, 강사 경력]. 행 단위 매핑은 §5.3 참고.

| 라벨           | 표시 내용                                                       |
| -------------- | --------------------------------------------------------------- |
| 성명(한글/영문)     | 이름 텍스트 + **배지**(조건부, 아래 2.3) / 영문 (§5: 한자 제거) |
| 생년월일       | 예: 1990.09.15 \| 만 35세                                       |
| 연락처·이메일  | 전화번호, 이메일                                                 |
| 성별 및 병역사항 | 남성·여성 / 군필·미필·면제                                       |
| 주소           | 주소 텍스트                                                     |
| 정산 계좌정보  | 승인 전 마스킹 / 승인 후 상세 (아래 2.2.1)                      |
| 최종학력·강사 경력 | "학력 \| 학교명", N년                                            |
| 한줄소개       | 한 줄 소개 텍스트 (전체 너비)                                   |

#### 2.2.1 정산 계좌정보 노출 규칙

- **강사 승인 전** (`approvalStatus !== 'approved'`): 은행명 + 계좌번호 마스킹 + 예금주 마스킹 (예: 농협 \*\*\*\*\*\*\*9012 \| 박\*\*).
- **강사 승인 후** (`approvalStatus === 'approved'`): 은행명 계좌번호 \| 예금주 상세 노출.

- **희망 배정 학교** (기본 정보 테이블 아래): 1~4순위를 **Radio.Group** 2×2 그리드로 표시. **1순위 디폴트 선택**. 1순위가 배정 불가(assignable: false)이면 선택 가능한 다음 순위를 디폴트로. 배정 불가 학교(인원 마감 등)는 해당 Radio **disabled**.
- **승인/반려 가능 조건**: **희망 배정 학교를 선택한 경우에만** 반려·승인 버튼 활성화. 미선택 시 비활성화.
- **액션 버튼 (우측 상단, 기본 정보 섹션과 같은 줄)**
  - **반려**: danger 스타일(붉은 테두리). 학교 선택 시에만 활성화.
  - **승인**: primary + modalTeal(녹색 배경). 학교 선택 시에만 활성화.
- **푸터**: **닫기** 버튼 1개(기존 TealHeaderModal footer 패턴).

### 2.3 강사명 옆 배지 (디자이너 스펙)

- **컴포넌트**: 기존 **ScheduleChangeHistoryBadge** 재사용.
  - 연한 녹색 배경, 흰색 글씨, 둥근 모서리.
  - 텍스트: "일정 변경&취소 이력 N회" (N은 실제 횟수).
- **노출 조건**: **일정 변경 또는 취소 이력이 1회 이상 존재할 때만** 강사명 옆에 표시.
  - 이력이 0회이면 배지를 렌더링하지 않음.
- **사이즈**: 기존 배지 컴포넌트 사이즈 유지(font-size 14px, padding 4px 10px 등). 강사명 텍스트와 어울리도록 인라인 배치.

### 2.4 탭: 강사 이력서

- **내용**: 강사 이력서 본문(텍스트/에디터 출력 등).
- **1차 구현**: 빈 영역 또는 "강사 이력서 내용이 없습니다." 등 플레이스홀더 표시.
- **향후**: 이력서 데이터 구조·API 확정 후 본문 연동.

## 3. 데이터 (기획 → 개발)

- **모달에 전달하는 데이터**: 신청 강사 한 명 분량. `ApplicantInstructorRow` 사용.
- **필드** (기본 정보·배지·희망 학교·계좌용):
  - `scheduleChangeCancelCount?: number` — 일정 변경&취소 이력. 1 이상일 때만 강사명 옆 배지 표시.
  - `oneLineIntro?: string` — 한줄소개.
  - `nameHanja?`, `nameEnglish?` — 성명 한자/영문.
  - `birthDate?`, `age?` — 생년월일·만 나이.
  - `gender?`, `militaryStatus?` — 성별·병역사항.
  - `bankName?`, `accountNumber?`, `accountHolder?` — 정산 계좌(승인 전 마스킹, 승인 후 상세).
  - `profileImageUrl?` — 프로필 사진(없으면 플레이스홀더).
  - `preferredSchools?: { schoolId, schoolName, rank, assignable }[]` — 희망 배정 학교 1~4순위. `assignable: false`인 학교는 Radio disabled.
- **Mock**: 목록 mock에 위 필드 포함. 일부 강사만 `scheduleChangeCancelCount >= 1`, `approvalStatus === 'approved'`, 4순위 `assignable: false`로 UI 검증.

## 3.5 모달 크기·바디 레이아웃 (디자이너 → 개발)

- **모달 외곽**: 가로 1400px, 세로 400px 고정. 헤더·푸터 고정, 바디만 스크롤 가능.
- **바디 사이즈**: 1400×400에 맞춰 내부 UI가 찌그러지지 않도록 다음 적용.
  - 기본 정보 영역: `table-layout: fixed`, 라벨/값 셀 너비 비율 고정(예: 라벨 140px 또는 15%, 값 85%).
  - 한줄소개 셀: 전체 너비, 필요 시 `max-height` + `overflow-y: auto`로 본문만 스크롤.
  - 탭·섹션 제목·버튼·테이블 간 간격은 모달 높이(400px) 내에 들어오도록 패딩/갭 조정.

## 5. 기본 정보 탭 테이블 수정 사항 (디자이너/기획/PM → 개발 위임)

**적용 기준**: 제공 시안(스크린샷) 및 테이블 필드 제거·추가·배치 우선 반영.  
**참조**: [persona.md](../../../.cursor/rules/process/persona.md) — 디자이너/기획/PM 요청 해석.

### 5.1 필드 제거

| 항목 | 내용 |
|------|------|
| **한자** | 성명 하위 행에서 **한자(라벨/값)** 제거. 시안에는 성명이 **한글 / 영문** 두 행만 노출됨. |

- 구현: 성명 rowSpan을 **3 → 2**로 변경하고, 한자용 `<tr>` 및 한자 라벨/값 셀 제거.
- 데이터: `nameHanja`는 API/목록용으로 유지해도 되며, 기본 정보 테이블에는 표시하지 않음.

### 5.2 필드 통합 (배치 변경)

| 항목 | 내용 |
|------|------|
| **성별 및 병역사항** | 현재 **성별**(라벨/값) · **병역사항**(라벨/값) 두 행 → **한 행**으로 통합. |
| 라벨 | **「성별 및 병역사항」** (단일 라벨). |
| 값 | **「남성 \| 군필」** 형태로 한 셀에 표시 (`gender \| militaryStatus`). 구분자 ` \| ` (공백+파이프+공백). |

- 구현: 성별 전용 행 제거. 우측 열에 「성별 및 병역사항」 라벨 1개 + 값 1개(통합 문자열)만 노출.

### 5.3 테이블 배치 (목표 구조)

시안 기준 **좌측 열** / **우측 열** 구분은 유지. 행 구성만 아래 순서로 정리.

**좌측 열 (라벨·값 쌍)**  
성명(한글, 영문) → 연락처 → 주소 → 최종 학력 → 한 줄 소개

**우측 열 (라벨·값 쌍)**  
생년월일 → 성별 및 병역사항 → 이메일 → 정산 계좌 정보 → 강사 경력

- **행 매핑 (좌 \| 우)**  
  - 1행: 성명(한글) \| 생년월일  
  - 2행: 성명(영문) \| 성별 및 병역사항  
  - 3행: 연락처 \| 이메일  
  - 4행: 주소 \| 정산 계좌 정보  
  - 5행: 최종 학력 \| 강사 경력  
  - 6행: 한 줄 소개 \| 값(전체 너비, colspan)

### 5.4 개발자 체크리스트 (수정 위임)

- [ ] **한자 제거**: 성명 하위에서 한자 행 삭제, 성명 rowSpan=2로 변경.
- [ ] **성별·병역 통합**: 「성별 및 병역사항」 단일 라벨, 값은 `{gender} \| {militaryStatus}` 형식.
- [ ] **배치 순서**: 위 5.3 행 매핑대로 좌/우 열 배치 (연락처 2행 우측, 주소 3행 좌측, 성별 및 병역 3행 우측, 이메일 4행 우측, 정산 계좌·강사 경력 5행 우측, 한 줄 소개 6행 전체).
- [ ] **colspan/rowSpan**: 6행 한 줄 소개 값 셀만 전체 너비(colspan) 유지.
- [ ] 기존 스타일 클래스·구분선(divider) 유지하여 시안과 동일한 시각 구조 유지.
