# 강의 신청 강사 상세 정보 모달 명세 (디자이너/기획/PM → 개발 위임)

**대상**: 신청자 목록 > 신청 강사 탭 — 강의 신청 강사 목록 테이블에서 **강사명 열 클릭** 시 노출되는 모달  
**참조 시안**: 제공된 스크린샷 (기본 정보 / 강사 이력서 탭, 강사명 옆 일정 변경&취소 이력 배지, 반려/승인/닫기 버튼)  
**관련 명세**: [program-detail-applicants-tab-spec.md](./program-detail-applicants-tab-spec.md)

---

## 1. 개요 (PM/기획)

- **트리거**: 강의 신청 강사 목록 테이블에서 **강사명** 열(또는 해당 행) 클릭 시 모달 오픈.
- **모달 제목**: 「강의 신청 강사 상세 정보」
- **목적**: 해당 강사의 기본 정보·이력서를 확인하고, 결재(반려/승인) 액션을 수행할 수 있게 한다.

---

## 2. 모달 구조 (디자이너 → 개발)

### 2.1 공통

- **컨테이너**: 기존 `TealHeaderModal` 재사용. 제목 영역(청록 헤더) + 본문 + 푸터(닫기 버튼).
- **본문**: **탭 2개** — 「기본 정보」 | 「강사 이력서」. 탭 전환 시 해당 패널만 표시.

### 2.2 탭: 기본 정보

- **섹션 제목**: "기본 정보" (탭 하단, 기존 학교 상세 모달의 섹션 타이틀 스타일 참고).
- **표시 형식**: Ant Design `Descriptions` 2열 테이블. **테이블 필드 순서(좌→우, 위→아래)** 는 아래와 같이 고정한다.
  - **1행**: 강사명(이름+배지) | 주소
  - **2행**: 연락처 | 이메일
  - **3행**: 강의 경력 | 최종 학력
  - **4행**: 한줄소개 (전체 너비, span 2)
- **레이아웃**: 라벨 열·값 열 너비 비율 고정(`table-layout: fixed`), 모달 바디(1400×400) 안에서 테이블이 넘치거나 찌그러지지 않도록 처리.

| 라벨      | 표시 내용                                       |
| --------- | ----------------------------------------------- |
| 강사명    | 이름 텍스트 + **배지**(조건부, 아래 2.3)        |
| 주소      | 주소 텍스트                                     |
| 연락처    | 전화번호                                        |
| 이메일    | 이메일 주소                                     |
| 강의 경력 | N년                                             |
| 최종 학력 | "학력 \| 학교명" (예: 4년제 졸업 \| 틴토대학교) |
| 한줄소개  | 한 줄 소개 텍스트 (전체 너비 한 줄)             |

- **액션 버튼 (우측 상단, 기본 정보 섹션과 같은 줄)**
  - **반려**: danger 스타일(붉은 테두리).
  - **승인**: primary + modalTeal(녹색 배경).
- **푸터**: **닫기** 버튼 1개(기존 TealHeaderModal footer 패턴).

### 2.3 강사명 옆 배지 (디자이너 스펙)

- **컴포넌트**: 기존 **ScheduleChangeHistoryBadge** 재사용.
  - 연한 녹색 배경, 흰색 글씨, 둥근 모서리.
  - 텍스트: "일정 변경&취소 이력 N회" (N은 실제 횟수).
- **노출 조건**: **일정 변경 또는 취소 이력이 1회 이상 존재할 때만** 강사명 옆에 표시.
  - 이력이 0회이면 배지를 렌더링하지 않음.
- **사이즈**: 기존 배지 컴포넌트 사이즈 유지(font-size 14px, padding 4px 10px 등). 강사명 텍스트와 어울리도록 인라인 배치.

### 2.4 탭: 강사 이력서

- **내용**: 강사 이력서 본문(텍스트/에디터 출력 등).
- **1차 구현**: 빈 영역 또는 "강사 이력서 내용이 없습니다." 등 플레이스홀더 표시.
- **향후**: 이력서 데이터 구조·API 확정 후 본문 연동.

## 3. 데이터 (기획 → 개발)

- **모달에 전달하는 데이터**: 신청 강사 한 명 분량.
  - 기존 `ApplicantInstructorRow` 확장 또는 상세 전용 타입 사용.
- **추가 필드 제안** (기본 정보·배지용):
  - `scheduleChangeCancelCount?: number` — 일정 변경&취소 이력 횟수. 0 또는 미존재 시 배지 미표시.
  - `oneLineIntro?: string` — 한줄소개.
- **Mock**: 목록 mock에 위 필드 포함. 일부 강사만 `scheduleChangeCancelCount >= 1`로 설정해 배지 노출 검증.

---

## 3.5 모달 크기·바디 레이아웃 (디자이너 → 개발)

- **모달 외곽**: 가로 1400px, 세로 400px 고정. 헤더·푸터 고정, 바디만 스크롤 가능.
- **바디 사이즈**: 1400×400에 맞춰 내부 UI가 찌그러지지 않도록 다음 적용.
  - 기본 정보 영역: `table-layout: fixed`, 라벨/값 셀 너비 비율 고정(예: 라벨 140px 또는 15%, 값 85%).
  - 한줄소개 셀: 전체 너비, 필요 시 `max-height` + `overflow-y: auto`로 본문만 스크롤.
  - 탭·섹션 제목·버튼·테이블 간 간격은 모달 높이(400px) 내에 들어오도록 패딩/갭 조정.

## 4. 구현 위임 체크리스트 (개발자)

- [ ] **모달 컴포넌트**: `ApplicantInstructorDetailModal`(가칭) 생성. `TealHeaderModal` 래핑, 탭(기본 정보 | 강사 이력서).
- [ ] **기본 정보 탭**: Descriptions 2열, **필드 순서** 1행 강사명|주소, 2행 연락처|이메일, 3행 강의 경력|최종 학력, 4행 한줄소개(span 2). 반려/승인 버튼 우측 상단, 닫기 푸터.
- [ ] **바디 레이아웃**: 모달 1400×400에 맞게 `table-layout: fixed`, 라벨/값 셀 너비 고정, 내부 UI 틀어짐 방지.
- [ ] **배지**: `ScheduleChangeHistoryBadge` 재사용. `scheduleChangeCancelCount > 0`일 때만 강사명 옆 렌더링. 사이즈는 기존 CSS 유지.
- [ ] **강사 이력서 탭**: 1차는 플레이스홀더 또는 안내 문구만 표시.
- [ ] **연동**: 신청 강사 테이블에서 강사명(또는 행) 클릭 시 선택 행을 state에 저장하고 모달 `open` + 선택 행 데이터 전달.
- [ ] **타입·Mock**: `ApplicantInstructorRow`에 `scheduleChangeCancelCount`, `oneLineIntro` 옵션 필드 추가. Mock 데이터에 일부 강사만 이력 1회 이상·한줄소개 설정.
