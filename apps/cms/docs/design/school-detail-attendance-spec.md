## 1. 회차·일정 라벨 (교육 구조별)

프로그램 **교육 구조**·**수업 회차 유형**에 따라 회차 패널·필터·엑셀의 **선행 라벨**이 달라진다. 강사 신청·참여 강사 캘린더의 일정 라벨도 같은 규칙을 쓴다.

### 회차와 차시는 다른 개념

- **회차**: 교육 일정 단위(`sessionNo`). 복수 회차는 회차마다 일정이 있다.
- **차시**: 커리큘럼 수업 단위(「차시 및 교육 내용」). 차시 **개수**를 `N차시`로 표기한다(예: `1회차 (2차시)`, 희망 차시 수 `3차시`).
- 회차 번호·지망 순위·순서·일정 건수를 `N차시`로, 차시 수를 `N회차`로 쓰지 않는다.
- **커리큘럼형 단일 회차는 하루만 진행**하며 그날 전 차시를 진행한다 → 차시 수 `N차시`.

| 구조 | 노출 텍스트 | 데이터 소스 |
|------|-------------|-------------|
| **사전교육** | `사전교육` | 일정 역할(사전교육) |
| **커리큘럼형 · 단일 회차** | `N차시` (차시 수, 예: `4차시`) | 일정의 연결 차시 수 → 없으면 공통정보 차시 개수(사전교육 제외) |
| **커리큘럼형 · 복수 회차** | `N회차`, 차시 수를 알면 `N회차 (K차시)` | 회차 = `sessionNo`, 차시 수 = 일정 값 → 없으면 공통정보 회차 행의 진행 차시 수 |
| **일정형** | **일정명** (예: 오리엔테이션, 온라인 워크숍) | `generalCommonInfo.scheduleDetails[n].name` |

### Fallback

- 커리큘럼형: 차시 수를 모르면 `{N}회차`
- 일정형: name 없음 → scheduleLabel → `세부 일정 NN`
- 캘린더: 선행 라벨을 모르면 시간만

### 표시 예시

**커리큘럼형 (단일 회차)**

- 패널 제목: `4차시 : 2026. 01. 09(금)`
- 필터 옵션: `4차시 · 2026. 01. 09(금)`

**커리큘럼형 (복수 회차)**

- 패널 제목: `1회차 (2차시) : 2026. 01. 09(금)` (차시 수 미상이면 `1회차 : …`)
- 필터 옵션: `1회차 (2차시) · 2026. 01. 09(금)`

**일정형**

- 패널 제목: `오리엔테이션 : 2026. 01. 09(금)`
- 필터 옵션: `오리엔테이션 · 2026. 01. 09(금)`

**캘린더 (강사 신청·참여 강사)**

- `4차시 (09:20 ~ 11:20)`, `2회차 (2차시) (09:20 ~ 11:20)`, `오리엔테이션 (09:20 ~ 11:20)`, `사전교육 (10:00 ~ 11:00)`

**공통 (16px 메타, table-description)**

- `{교육 시간} ({대면/온라인}) | {교시 구간}` — 예: `2시간 (대면) | 1교시 (9:20 ~ 10:10) ~ 2교시 (10:20 ~ 11:10)`

## 2. 화면 구성

1. **필터** (FilterTableLayout, 탭 제목·전역 엑셀 없음)
   - 교육 일정, 학생명, 성별, 학급, 출결 현황 + [조회]
2. **회차별 패널** (필터 결과에 따라 1개 이상)
   - 헤더: `{선행 라벨} : {날짜}` + 메타 + `총 N건`
   - 액션: [저장] … [엑셀] (엑셀 맨 오른쪽)
   - 학생 테이블: No., 학생명, 성별, 생년월일, 학급, 연락처, 이메일, 출결(출석/결석/지각, large 라디오)
