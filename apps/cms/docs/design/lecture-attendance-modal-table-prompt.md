# 강의 출석 내역 모달 — 테이블 구현 프롬프트 (디자이너/기획·PM → 개발자)

**역할**: 디자이너·기획·PM이 개발자에게 전달하는 구현 지시  
**대상**: `LectureAttendanceModal` 바디 내 출석 내역 테이블  
**참조**: [lecture-attendance-modal-spec.md](./lecture-attendance-modal-spec.md), 시안 스크린샷

---

## 1. 목적 (PM/기획)

- **화면**: 학교 상세 모달 > 학생 명단 > 「강의 출석 내역」 클릭 시 노출되는 **강의 출석 내역** 모달.
- **역할**: 해당 학생의 **학생명·참석률**과 **회차별 출석 상태**(출석 완료 / 결석 / 강의 미진행)를 **한 개의 테이블**로만 표시한다.
- **동작**: 테이블 바디 영역은 **선택 불가·텍스트 전용**이며, 셀 클릭 등 추가 인터랙션은 두지 않는다.

---

## 2. 테이블 구조 (기획)

- **행·열**: 4열 × N행.
  - **1행(요약)**: 학생명 | (학생 이름) | 참석률 | (N% (강의 진행 회차 기준))
  - **2행 이후**: 1회차 | (상태) | 2회차 | (상태) … 순서로, **한 행에 회차 두 개씩** 라벨|값 쌍으로 채운다. 회차 수가 홀수면 마지막 행의 3·4열은 한 쌍만 채우고 나머지는 비운다.
- **순서**: 열 순서는 **항상 [라벨1 | 값1 | 라벨2 | 값2]** 이며, 행 순서는 **요약 행 → 1·2회차 → 3·4회차 → …** 를 지킨다. 회차 수는 프로그램/학교마다 다르므로 **동적**으로 처리한다.

---

## 3. 테이블 스펙 (디자이너 → 개발)

### 3.1 전체 치수

| 항목                | 값                | 비고                                  |
| ------------------- | ----------------- | ------------------------------------- |
| 테이블 전체         | **700px × 144px** | 고정. 모달 바디 내 하나의 테이블 블록 |
| 행 높이             | **48px**          | 모든 행 동일 (144 ÷ 3행 = 48px 등)    |
| 라벨 열(1·3열) 너비 | **144px**         | 고정                                  |
| 값 열(2·4열) 너비   | 나머지 균분       | 4열 합 = 700px 유지                   |

### 3.2 열별 스타일

| 열  | 역할                             | 너비  | 배경                  | 글자       | 정렬 |
| --- | -------------------------------- | ----- | --------------------- | ---------- | ---- |
| 1열 | 라벨(학생명, N회차)              | 144px | 연한 회색(#fafafa 등) | 굵게(bold) | 좌측 |
| 2열 | 값(이름, 참석률 문구, 출석 상태) | 가변  | 흰색                  | 일반       | 좌측 |
| 3열 | 라벨                             | 144px | 연한 회색             | 굵게       | 좌측 |
| 4열 | 값                               | 가변  | 흰색                  | 일반       | 좌측 |

### 3.3 테이블·셀 공통

- **테이블 외곽**: `border-radius` 적용(예: 4px~8px), 얇은 연한 회색 테두리. 셀 간 구분선 가로·세로 모두 표시.
- **셀**: 모든 셀 **좌측 정렬**, 적절한 좌측 패딩(예: 12px~16px)으로 가독성 확보.
- **바디(값 셀)**: **텍스트만 표시**. 선택 불가(`user-select: none`), 버튼/링크/호버 효과 없음.

### 3.4 표시 문구

- 참석률 값: **"{N}% (강의 진행 회차 기준)"** (N은 정수).
- 회차 상태: **"출석 완료"** / **"결석"** / **"강의 미진행"** — 기존 `LECTURE_ATTENDANCE_STATUS_LABELS` 매핑 사용.

---

## 4. 데이터·구현 참고 (기획 → 개발)

- **입력**: `LectureAttendanceDetail` — `studentName`, `attendanceRatePercent`, `sessions: { roundNumber, status }[]`.
- **1행**: 학생명, `studentName`, 참석률, `attendanceRatePercent + "% (강의 진행 회차 기준)"`.
- **이후 행**: `sessions`를 순서대로 두 개씩 묶어, (N회차, 상태 라벨), (N+1회차, 상태 라벨) 형태로 채운다. 회차 수 가변에 대비해 동적 행 생성.

---

## 5. 개발자 체크리스트

- [ ] 테이블 전체 700×144px, 행 높이 48px 고정.
- [ ] 1·3열 144px, 연한 회색 배경, 굵은 글씨, 좌측 정렬.
- [ ] 2·4열 가변 너비, 흰 배경, 일반 글씨, 좌측 정렬.
- [ ] 모든 셀 좌측 정렬, 셀 경계선 명확, 테이블 모서리 둥글게.
- [ ] 바디(값) 영역 텍스트만 표시, 선택 불가, 인터랙션 없음.
- [ ] 회차 수 가변 시에도 열 순서(라벨|값|라벨|값) 및 행 순서(요약 → 1·2회차 → 3·4회차 …) 유지.
- [ ] 모달 푸터 「닫기」 버튼은 기존 TealHeaderModal 패턴 유지(가운데, 청록 아웃라인).
