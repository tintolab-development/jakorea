# 프로그램 상세 신청자 목록 탭 명세 (디자이너/기획/PM → 개발 위임)

**대상**: 프로그램 상세 페이지 > **신청자 목록** 탭  
**참조 시안**: 스크린샷 (프로그램 상세 신청자 목록 — 신청 학교 탭 / **신청 강사 탭**: 필터 학교명·강사명·결재 현황, 강의 신청 강사 목록 총 N건 테이블)  
**기존 참고 UI**: [ProgramProgressTab](../../../src/features/program/general/ui/detail-modal/program-status/program-progress-tab.tsx) — 서브 탭·필터·조회 버튼·테이블·건수 표시 패턴 재사용

---

## 1. 개요 (PM/기획)

- **목적**: 해당 프로그램에 대한 **수강 신청 학교** 및 **수강 신청 강사** 목록을 조회·필터링할 수 있게 한다.
- **사용자**: 관리자(ADMIN). 신청 현황 확인 및 (향후) 결재 처리 플로우 연동 가능성을 고려한 UI.
- **범위**: **신청 학교** 탭(1차) 구현 완료. **신청 강사** 탭은 본 명세 §4 기준으로 동일 패턴(필터·조회·테이블)·강사 전용 필드로 구현.

---

## 2. 레이아웃 및 공통 사양 (디자이너 → 개발)

### 2.1 탭 컨테이너

- 프로그램 상세 페이지의 메인 탭 중 **「신청자 목록」** 탭 선택 시 본 콘텐츠 표시.
- **URL**: 기존 `?tab=applicants` 유지 (`use-program-detail-tab.ts` 연동).
- 본 탭 내부는 **서브 탭 2개** + **필터 영역** + **테이블 영역**으로 구성.

### 2.2 전체 래퍼 (기존 진행 현황 탭과 동일 패턴)

| 항목               | 값                                                                                                     | 비고                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------- |
| **래퍼**           | `Card` (border false, 배경 `var(--color-bg-base)`)                                                     | `program-progress-tab__card` 스타일 참고 |
| **내부 패딩**      | 상 16px, 좌우 24px, 하 24px                                                                            | 기존 탭과 동일                           |
| **상단 블록**      | 서브 탭 + 필터 한 줄 (space-between, wrap 가능)                                                        | 탭 좌측, 필터·조회 우측                  |
| **구분선**         | 테이블 영역과 구분용 Divider                                                                           | `program-progress-tab__divider` 참고     |
| **테이블 위 헤더** | 신청 학교: "수강 신청 학교 목록 N건" / 신청 강사: "강의 신청 강사 목록 총 N건" + (향후 액션 버튼 영역) | N은 필터 적용 후 건수                    |

### 2.3 서브 탭 (신청 학교 | 신청 강사)

- **위치**: 카드 상단 좌측.
- **스타일**: 기존 진행 현황 탭 서브 탭과 동일.
  - 컨테이너: 배경 `var(--color-bg-tab)`, border-radius 8px, padding 4px.
  - **활성**: 흰 배경, 청록 테두리(`var(--color-tab-active)`), 청록 텍스트, font-weight 600.
  - **비활성**: 배경 `var(--color-bg-tab)`, 회색 텍스트, 호버 시 청록 텍스트.
- **라벨**:
  - 탭1: **신청 학교**
  - 탭2: **신청 강사**
- **URL 연동**: 서브 탭 상태는 쿼리 파라미터로 유지 권장 (예: `?tab=applicants&subTab=schools` / `subTab=instructors`). 기본값 `schools`.

## 3. 신청 학교 탭 상세

### 3.1 필터 영역

필터와 **조회** 버튼을 한 줄에 배치 (기존 진행 현황 탭과 동일 레이아웃).  
**조회** 버튼 클릭 시에만 필터 값이 적용되며, 테이블 데이터가 갱신된다.

| 필터 라벨       | 타입                  | 옵션                                  | 비고                                 |
| --------------- | --------------------- | ------------------------------------- | ------------------------------------ |
| **학교명**      | Select                | 전체 + (API/목록 기반 학교 목록)      | 기본값 "전체"                        |
| **지역**        | Select                | 전체 + 지역 목록                      | 기존 `REGION_OPTIONS` 등 재사용 가능 |
| **대상 학년**   | Select                | 전체 + 1~6학년                        | 기존 `GRADE_OPTIONS` 참고            |
| **담당 교사명** | Select 또는 검색 입력 | 전체 + (API/목록 기반)                | 기본값 "전체"                        |
| **결재 현황**   | Select                | 전체, 승인 대기, 신청 반려, 승인 완료 | 아래 3.3 결재 현황 값과 매핑         |
| **(우측)**      | **버튼**              | **조회**                              | primary, 클릭 시 필터 적용           |

- 각 Select는 **placeholder 또는 기본값 "전체"**.
- 필터 옵션 목록은 백엔드 API 또는 기존 상수와 연동. 초기에는 mock 목록으로 구현 가능.

### 3.2 테이블: 수강 신청 학교 목록

- **헤더 문구**: "수강 신청 학교 목록 **N건**" (N = 조회 적용 후 행 개수).
- **테이블 컬럼** (스크린샷 기준):

| 컬럼명       | 데이터 타입 | 표시 형식  | 비고                                              |
| ------------ | ----------- | ---------- | ------------------------------------------------- |
| No.          | number      | 1부터 순번 | 중앙 정렬, 너비 72px 수준                         |
| 참여 학교명  | string      | 텍스트     | 중앙 정렬                                         |
| 지역         | string      | 텍스트     | 예: 서울특별시 강서구                             |
| 대상 학년    | string      | 텍스트     | 예: 5학년                                         |
| 대상 학급 수 | number      | "N개"      | 예: 6개                                           |
| 총 학생 수   | number      | "N명"      | 예: 176명                                         |
| 담당 교사    | string      | 텍스트     | 예: 홍길동                                        |
| 결재 현황    | enum        | **뱃지**   | 승인 대기 / 신청 반려 / 승인 완료 (아래 3.3 스펙) |

- **행 스타일**: 짝수/홀수 행 배경 교차(옅은 회색/흰색)로 가독성 확보 (기존 테이블 CSS 참고).
- **페이지네이션**: 30건 이상 등 데이터가 많을 경우를 대비해 페이지네이션 또는 스크롤 정책을 개발 단계에서 적용. (1차는 pagination false로 목록만 표시해도 무방.)

### 3.3 결재 현황 뱃지 스펙 (디자이너)

결재 현황 컬럼은 **버튼/태그 형태의 뱃지**로 표시한다. (클릭 시 동작은 향후 결재 처리 기능 연동 시 정의.)

| 값 (예시 코드) | 라벨      | 스타일 (스크린샷 기준)                   |
| -------------- | --------- | ---------------------------------------- |
| `pending`      | 승인 대기 | 파란색 테두리 + 파란색 텍스트, 흰색 배경 |
| `rejected`     | 신청 반려 | 붉은색 테두리 + 붉은색 텍스트, 흰색 배경 |
| `approved`     | 승인 완료 | 회색 테두리 + 회색 텍스트, 흰색 배경     |

- 뱃지: box-sizing border-box, padding 6px 10px, border 1px solid, border-radius 6px, font-size 14px, font-weight 600.
- 색상은 디자인 토큰 우선: primary(파란), error(빨강), default/neutral(회색). 기존 `SettlementStatusBadge` / `TextbookStatusBadge` 패턴 참고하여 **결재 현황 전용 뱃지 컴포넌트** 추가 권장.

## 4. 신청 강사 탭 상세 (디자이너/기획 → 개발 위임)

**참조 시안**: 스크린샷 (신청자 목록 — 신청 강사 서브 탭, 필터, 강의 신청 강사 목록 테이블)

### 4.1 필터 영역

필터와 **조회** 버튼을 한 줄에 배치 (신청 학교 탭·진행 현황 탭과 동일 레이아웃).  
**조회** 버튼 클릭 시에만 필터 값이 적용되며, 테이블 데이터가 갱신된다.

| 필터 라벨     | 타입     | 옵션                                  | 비고                                            |
| ------------- | -------- | ------------------------------------- | ----------------------------------------------- |
| **학교명**    | Select   | 전체 + (API/목록 기반 학교 목록)      | 기본값 "전체"                                   |
| **강사명**    | Select   | 전체 + (API/목록 기반 강사 목록)      | 기본값 "전체"                                   |
| **결재 현황** | Select   | 전체, 승인 대기, 신청 반려, 승인 완료 | 3.3 결재 현황 뱃지와 동일 값·동일 배지 컴포넌트 |
| **(우측)**    | **버튼** | **조회**                              | primary, 클릭 시 필터 적용                      |

- 각 Select는 **placeholder 또는 기본값 "전체"**.
- 필터 옵션(학교명, 강사명)은 백엔드 API 또는 mock 목록. 초기에는 mock 배열로 구현 가능.

### 4.2 테이블: 강의 신청 강사 목록

- **헤더 문구**: "**강의 신청 강사 목록** 총 **N건**" (N = 조회 적용 후 행 개수). 스크린샷 예: "강의 신청 강사 목록 총 72건".
- **테이블 컬럼** (스크린샷 기준):

| 컬럼명    | 데이터 타입 | 표시 형식                    | 비고                                                                                                                                                                |
| --------- | ----------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No.       | number      | 1부터 순번(역순 노출 가능)   | 중앙 정렬, 너비 72px 수준                                                                                                                                           |
| 강사명    | string      | 텍스트                       | 예: 김틴토, 이틴토                                                                                                                                                  |
| 강의 경력 | string      | "N년"                        | 예: 1년, 5년, 7년                                                                                                                                                   |
| 최종 학력 | string      | "학력 \| 학교명" (구분자 \|) | 예: 4년제 졸업 \| 틴토대학교, 2년제 졸업 \| 틴토전문대학교, 고등학교 졸업 \| 틴토고등학교, 4년제 휴학 \| 틴토대학교, 4년제 중퇴 \| 틴토대학교, 대학원 \| 틴토대학원 |
| 연락처    | string      | 전화번호                     | 예: 010-0000-0000                                                                                                                                                   |
| 이메일    | string      | 이메일 주소                  | 예: tinto.naver.com                                                                                                                                                 |
| 주소      | string      | 텍스트                       | 예: 서울특별시 강서구                                                                                                                                               |
| 결재 현황 | enum        | **뱃지**                     | 승인 대기 / 신청 반려 / 승인 완료 — **교재 현황과 동일 배지 컴포넌트(TextbookStatusBadge variant=approval)** 사용, 배경/텍스트색만 결재용으로 적용                  |

- **행 스타일**: 짝수/홀수 행 배경 교차(옅은 회색/흰색). 신청 학교 탭·기존 테이블 CSS와 동일.
- **결재 현황 뱃지**: 3.3과 동일. 기존 `ApprovalStatusBadge`(＝ TextBookStatusBadge variant approval) 재사용.

### 4.3 데이터 스키마 (강사 신청 목록 행)

| 필드(예시)             | 타입   | 비고                                                                            |
| ---------------------- | ------ | ------------------------------------------------------------------------------- |
| id                     | string | 행 키                                                                           |
| no                     | number | 순번                                                                            |
| instructorName         | string | 강사명                                                                          |
| lectureExperienceYears | number | 강의 경력(년) → "N년" 표시                                                      |
| educationLevel         | string | 학력(예: 4년제 졸업, 2년제 졸업, 고등학교 졸업, 4년제 휴학, 4년제 중퇴, 대학원) |
| schoolName             | string | 최종 학력 학교명 → "학력 \| 학교명" 조합                                        |
| contact                | string | 연락처                                                                          |
| email                  | string | 이메일                                                                          |
| address                | string | 주소                                                                            |
| approvalStatus         | enum   | pending / rejected / approved                                                   |

- 초기에는 **mock 데이터**로 테이블 렌더링. 72건 등 충분한 건수로 목록·필터 동작 검증.
