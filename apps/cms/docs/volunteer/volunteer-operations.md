## 🎯 봉사자 운영 개요

### 기본 특성

봉사자는 강사와 유사한 운영 플랫폼을 사용하지만, 다음과 같은 차이점이 있습니다:

- **정산 방식**: 강사비 없음 → **봉사시간으로 관리(1365 연계)**
- **운영 단위**: 학기(기수) 단위 운영, 지역별 선발
- **매칭 방식**: 학교 매칭 후 **2인 1조 순환 배정**
- **명칭**: 향후 "강사"보다 **"교육 진행자"**로 통일하여 확장성 고려

### 봉사자 유형

- **대학생 경제교육 봉사단**: 주요 대상
- 기타 봉사자 프로그램

## 🔄 운영 프로세스

### 1. 지원/선발

- 봉사자 신청
- 지역별 선발
- 면접 및 승인 프로세스

### 2. 배치

- 학교 매칭
- **2인 1조 순환 배정**
- 매칭 기준:
  - 개인별 교육 횟수 균등
  - 파트너 중복 최소화
  - 지역 분배 등

### 3. 활동보고

- 교육 계획서 작성 및 제출
- 활동 보고서 작성 및 제출
- 교육 진행 내역 기록

### 4. 봉사시간 산출

- 활동 내역 기반 봉사시간 자동 산출
- 1365 연계
- 봉사 인증서 발급 (향후)

---

## 👥 매칭 시스템

### 2인 1조 순환 배정

봉사자는 항상 **파트너와 함께 배정**됩니다.

#### 매칭 기준

1. **개인별 교육 횟수 균등**
   - 모든 봉사자가 비슷한 횟수의 교육을 진행하도록 배정

2. **파트너 중복 최소화**
   - 같은 파트너와 반복적으로 배정되지 않도록 최소화
   - 다양한 파트너와의 협업 경험 제공

3. **지역 분배**
   - 지역별로 균등하게 배정
   - 이동 거리 고려

4. **기타 고려 사항**
   - 학교 요구사항
   - 프로그램 특성
   - 봉사자 선호도 (향후)

#### 현재 상태

- **현재**: 수작업으로 매칭
- **향후**: 자동 매칭 시스템 구축 예정

## ⏰ 봉사시간 관리

### 1365 연계

봉사시간은 **1365 자원봉사 포털**과 연계하여 관리됩니다.

#### 봉사시간 산출 기준

- 교육 시간
- 준비 시간
- 이동 시간 (일부 케이스)
- 보고서 작성 시간 (일부 케이스)

#### 봉사시간 관리 프로세스

1. **활동 보고서 제출**
   - 교육 진행 내역 기록
   - 교육 계획서 확인

2. **봉사시간 자동 산출**
   - 활동 내역 기반 자동 계산
   - 관리자 승인 프로세스

3. **1365 연계**
   - 봉사시간 내보내기
   - 인증서 발급 (향후)

## 🔄 강사와의 차이점

### 비교표

| 항목 | 강사 (INSTRUCTOR) | 봉사자 (VOLUNTEER) |
|------|------------------|-------------------|
| **정산** | 강사비/교통비/숙박비 정산 | 봉사시간 관리 (1365 연계) |
| **매칭** | 1인 배정 | 2인 1조 순환 배정 |
| **운영 단위** | 프로그램별 | 학기(기수) 단위 |
| **선발** | 개별 선발 | 지역별 선발 |
| **이력 관리** | 강사 이력 관리 | 봉사단 참여 이력 |
| **인증서** | 강사 인증서 | 봉사 인증서 (1365 연계) |
| **보고서** | 강의 보고서 | 활동 보고서 |
| **만족도 조사** | 강사 만족도 조사 | 프로그램 만족도 조사 |

### 공통점

- 교육 진행자로서의 역할
- 프로그램 신청 및 참여
- 교육 계획서 작성
- 보고서 제출
- 이력 관리

## 💻 시스템 요구사항

### 필수 기능

1. **봉사자 관리**
   - 봉사자 정보 관리
   - 지역별 선발 관리
   - 면접 및 승인 프로세스

2. **매칭 시스템**
   - 학교-봉사자 매칭
   - 2인 1조 순환 배정
   - 매칭 기준 자동화 (향후)

3. **활동 관리**
   - 교육 계획서 작성 및 제출
   - 활동 보고서 작성 및 제출
   - 교육 진행 내역 기록

4. **봉사시간 관리**
   - 봉사시간 자동 산출
   - 1365 연계
   - 봉사시간 통계

5. **이력 관리**
   - 참여 이력 조회
   - 봉사시간 이력
   - 인증서 발급 (향후)

### 향후 확장 기능

1. **자동 매칭 시스템**
   - 매칭 기준 자동화
   - 파트너 중복 최소화 알고리즘
   - 지역 분배 자동화

2. **1365 연계 강화**
   - 실시간 연동
   - 자동 내보내기
   - 인증서 자동 발급

3. **통계 및 리포팅**
   - 봉사자별 통계
   - 지역별 통계
   - 프로그램별 통계

## 📌 참고사항

### 명칭 통일

향후 "강사"와 "봉사자"를 **"교육 진행자"**로 통일하여 확장성을 고려합니다.

### 운영 플랫폼 통합

봉사자 운영은 강사 운영과 유사한 플랫폼으로 통합하여:
- 일관된 사용자 경험 제공
- 운영 효율성 향상
- 데이터 통합 관리

### 자동화 우선순위

1. **봉사시간 산출 자동화** (최우선)
2. **매칭 시스템 자동화** (중기)
3. **1365 연계 자동화** (중기)
4. **인증서 자동 발급** (장기)
