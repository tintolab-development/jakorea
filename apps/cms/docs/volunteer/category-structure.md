## 🌳 전체 카테고리 트리

```
홈
├── 검색
├── 알림 리스트
├── 내 봉사 현황
│   ├── 신청 완료 🦆
│   ├── 진행 예정
│   ├── 진행 중
│   └── 진행 완료 🦆
└── 배너 🦆

진행 프로그램
├── 검색
├── 카테고리 솔팅
├── 진행 기간 🦆
├── 수강 대상
├── 교육 유형
├── 진행 상태 🦆
├── 프로그램 목록 🦆
├── 프로그램 상세 🦆
├── 찜하기(관심 등록) 🦆
└── 프로그램 수강 신청 🦆

봉사단
├── 개인정보관리
│   └── 개인정보 관리
├── 프로그램관리
│   ├── 수강 프로그램 🦆
│   │   ├── 프로그램 상세 이력/현황 🦆
│   │   ├── 교육 계획서 작성 및 제출 🦆
│   │   └── 만족도 조사 🦆
│   └── 관심 프로그램 관리 🦆
│       └── 프로그램 상세 🦆
└── 봉사단 활동 관리
    ├── 내 봉사 일정 🦆
    └── 봉사단 참여 이력 🦆

──────────────────── (divider)

공지사항
└── 문의하기

FAQ

문의하기
```

> 🦆 표시는 오리 아이콘이 표시된 항목 (중요 기능 또는 개발 예정)

## 🗺️ 메뉴 구조 매핑

### 현재 메뉴 구조와의 매핑

| IA 카테고리 | 현재 메뉴 경로 | 상태 | 비고 |
|------------|--------------|------|------|
| 홈 | `/` | ✅ | 대시보드 |
| 진행 프로그램 | `/programs` | ✅ | 공유 메뉴 |
| 봉사단 | `volunteers-user-group` | ✅ | 메뉴 그룹만 존재 |
| ├─ 개인정보관리 | `/mypage/profile` | ✅ | 공유 메뉴 |
| ├─ 프로그램관리 | - | ⚠️ | 부분 구현 |
| │  ├─ 수강 프로그램 | `/volunteers/my/programs` | ✅ | 봉사 프로그램 목록으로 구현됨 |
| │  └─ 관심 프로그램 관리 | `/programs/favorites` | ✅ | 공유 메뉴 |
| └─ 봉사단 활동 관리 | - | ⚠️ | 부분 구현 |
|    ├─ 내 봉사 일정 | - | ❌ | 미구현 |
|    └─ 봉사단 참여 이력 | `/histories` | ✅ | 기본 구현만 |
| 공지사항 | `/notices` | ✅ | 공유 메뉴 |
| FAQ | `/posts/faq` | ✅ | 공유 메뉴 |
| 문의하기 | `/posts/inquiries` | ✅ | 공유 메뉴 |

### 권한별 메뉴 표시

#### VOLUNTEER 권한 사용자에게 표시되는 메뉴

```
홈 (/)
진행 프로그램 (/programs)
봉사단
├── 봉사 프로그램 (/volunteers/my/programs)
마이페이지
├── 개인정보 관리
│   ├── 개인정보 관리 (/mypage/profile)
│   └── 봉사 이력 관리 (/histories)
└── 프로그램 관리
    └── 관심 프로그램 관리 (/programs/favorites)
────────────────────
공지사항 (/notices)
FAQ (/posts/faq)
문의하기 (/posts/inquiries)
```
