# 251120*JA코리아*인터뷰 미팅 요약 (2026.01.06, 105분)

## 1) 한 줄 요약

JA코리아는 **학교-강사-봉사자 운영을 엑셀/메일/밴드/폼즈로 분산 처리**하고 있으며, 특히  
**(1) 매칭/공지/서류 발송**, **(2) 강사비·교통비 정산 및 지급조서 취합**, **(3) 실적 데이터 취합**이 큰 병목이다.  
→ **단일 시스템에서 “신청 → 운영 → 정산 → 실적”까지 데이터가 누적·추출되는 구조**를 원함.

---

## 2) 현재 운영 흐름(As-is) 요약

### A. 학교 모집/확정

- 학교 대상 공문/유선/후원사 경로 등으로 모집 → **폼 링크 신청(가장 일반적)**
- 신청 정보는 **엑셀로 옮겨 관리**
- 신청 내용 부정확 시 담당자가 **학교에 재안내/확인(메일 회신 필수 등)**

### B. 강사 매칭/공지

- 확정 일정표를 **밴드에 게시 → 강사들이 신청 → 담당자가 배정**
- 배정 시 고려 요소
  - 강사 자택 ↔ 학교 주소 비교(지도 비교 등 수작업)
  - 기존 배정량/이동거리/지역 분배 등 **담당자 판단**이 섞임
- 배정 후
  - 강사/학교에 교육 정보(주소, 학년/학급, 교재, 서류 등)를 **단톡/개별 채팅 + 메일**로 전달
  - 머지로 문안 생성은 일부 하고 있으나 **발송 자체는 수작업**

### C. 교재 배송/변경 이슈

- 학년별 자체 교재/키트 수량 산정(엑셀 수식) → 창고 발송
- 일정 변경/취소가 잦음
  - **학교가 “갑”**이라 현실적으로 맞춰줄 수밖에 없음
  - 강사 취소는 상대적으로 적고 “2주/1주 전 통보” 정도의 내부 권고 가능

### D. 교육 종료 후 정산/지급

- 강의 종료 후 보고서(폼즈) 제출 → 이를 기반으로 **강사비/교통비/숙박비 산정**
- 산정 결과를 강사별 **PDF로 만들어 검토 요청(맞는지 확인)**
- 내부 룰: **매달 셋째 주 화요일 지급**
- 강사는 직원이 아니라 지출결의 직접 불가 → **강사 지급조서** 받아 JA가 지출결의 작성

### E. 실적 데이터(성과) 취합

- 매년/분기별로 실적(학교 수, 학생 수, 교사 수, 봉사자 수, 기업 수 등)을 **수기로 엑셀에 누적**
- “신청이 시스템에서 이뤄지면 데이터가 자동 누적되니, 실적용 로우데이터를 엑셀로 추출하고 싶다”
- 후원사별 결과보고 양식이 달라 **고정형 PDF 보고서 자동생성은 부담**
  - 대신 “로우데이터 + 간단 시각화(그래프 보기)” 니즈 존재

## 3) 가장 큰 Pain Point(병목)

1. **커뮤니케이션/서류 발송이 수작업**
   - 단톡방 생성/공지, 학교 메일 발송, 서류 요청 등 “발송” 반복 업무
2. **강사비 정산 프로세스가 복잡**
   - 시간(1~6시간), 교통비, 숙박비, 예외 케이스를 엑셀로 별도 계산
   - PDF 생성→검토→지급조서 수집→지출결의… 단계가 길고 번거로움
3. **데이터가 여러 툴에 분산**
   - Forms/Excel/Band/메일/문서24 등으로 흩어져 이력 조회가 어려움
4. **변수(프로그램·후원사·운영방식)가 많아 표준화가 어려움**
   - 후원사→프로그램→세부프로그램 계층 + 오프라인/온라인/기관교육/학생개별모집 등 케이스 다양

## 4) 운영 규칙/정책(정산/운영 핵심 룰)

### 정산 룰

- 강사비: **1~6시간 기준표 존재**
- 교통비: **왕복 60km 미만 미지급**, 차량 기준(주유/톨비 포함 개념)
  - KTX 등 실비는 원칙적으로 안 함(차량 기준 일괄)
- 숙박비: **일괄 8만원**
- 지급: **매달 셋째 주 화요일**
- 지급 전: 강사별 산정내역 **PDF 검토 완료** 필요
- 지급조서: 강사가 작성/제출 → JA가 지출결의 작성

### 취소/변경 정책 방향

- **즉시 취소 버튼은 위험**(취소 리스크 큼)
- 제안: “정책상 3일 전 이후 취소 불가” 또는 “취소는 담당자 컨택 필수”
- 강사 취소 이력은 내부 평가/면접 참고 등 **이력 관리 니즈**

---

## 5) 원하는 To-be 기능(요구사항) 정리

### ① 계정/데이터 구조

- **강사(교육 진행자)**: 주소, 정산정보(지급조서용), 참여 이력, 증명서/이수증 등
- **학교/교사**
  - 신청은 교사가 하되 데이터는 **학교 단위로 누적**
  - 교사 전근: 교사 계정 이동 가능하되 **과거 데이터는 학교에 남아야 함**
- **중복 신청 방지**
  - 같은 학교에서 같은 프로그램을 동시에 2명이 신청하는 문제
  - 예: “같은 학교+같은 학년 중복은 막고, 학년이 다르면 허용” 같은 룰 고려

### ② 매칭/일정 운영

- 학교/프로그램 기간(신청 가능 기간) 관리
- 강사 배정 시 **주소 기반 거리 산출 + 배정량 균형** 참고
- 변경/취소 발생 시 알림 및 재매칭 흐름(단, 학교 취소는 제한 필요)

### ③ 커뮤니케이션 자동화

- 단계별 알림(확정/매칭/교육임박/배송/서류요청 등) 이메일·문자
- FAQ
  - “JA 공통 FAQ”보다 **프로그램별 FAQ**가 유효

### ④ 정산 자동화(강한 니즈)

- 강의보고/만족도/결과보고 데이터 기반 **강사비 자동 산출**
- 교통비/숙박비 룰 반영 + 예외 케이스 관리
- 강사별 정산내역 PDF 생성(검토용) + 지급조서 정보 수집(폼 입력→다운로드)
- “외부 지원으로 JA가 지급하면 안 되는 강사” 등 **케이스 분기 필요**
- 강사비 단가가 케이스별로 다름
  - 예: 구글/자체섭외 강사 2차시 28만원 vs 강사교육 2차시 17만원 등

### ⑤ 실적/리포팅

- 최우선 출력: **엑셀(로우데이터)**
- 추가 니즈: 간단 시각화(폼즈처럼 자동 그래프 → 캡처 활용 가능)
- 후원사별 결과보고서 PDF 자동화는 커스터마이징 부담으로 우선순위 낮음(또는 제한적)

### ⑥ 평가/이력 관리

- 강사 취소 이력/참여 이력/내부 참고용 표시(주의 등)
- 학교도 무단취소 반복/협조 문제 시 내부 참고 표시 니즈

## 6) 봉사자(대학생 경제교육 봉사단 등) 운영 요약

- 강사비 없음 → **봉사시간으로 관리(1365 연계)**
- 학기(기수) 단위 운영, 지역별 선발, 학교 매칭 후 **2인 1조 순환 배정**
- 매칭 기준: 개인별 교육 횟수 균등 + 파트너 중복 최소화 등(현재 수작업)
- 니즈
  - 지원/선발/배치/활동보고/봉사시간 산출까지 **강사와 유사한 운영 플랫폼으로 통합 가능**
  - 명칭도 “강사”보다 **“교육 진행자”**로 통일하면 확장성 있음

---

## 7) 특이/리스크 포인트

- **구글(제미나이) 프로그램은 구글 폼/스프레드시트 사용이 사실상 강제**(파트너 요구)
  - 대안
    - (a) 담당자가 주기적으로 데이터 이관(다운로드→업로드)
    - (b) 구글 스프레드시트를 원본으로 두고 시스템이 읽어오는 방식(컬럼 고정 전제)
- 교사 연수 강사는 교사 비중이 높아 **노쇼가 많음** → 프리랜서 강사 확보 필요

---

## 8) 우선순위(정성)

1. **정산(강사비/지급조서/지출결의용 자료) 자동화**
2. **매칭/공지/서류 발송 등 반복 커뮤니케이션 자동화**
3. **실적 로우데이터 자동 누적 + 엑셀 추출**
4. (중장기) 봉사자까지 확장한 “교육 진행자” 통합 운영
