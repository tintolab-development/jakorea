# DnD 위젯 대시보드 수동 테스트 체크리스트

`/index2`에서 **DraggableDashboard** + **DraggableWidgetCard** 사용 시 확인할 항목.

## 0a. 2열 정렬 + 밀집 (Strict x alignment + auto-fill)

- [ ] **중간 위치 없음**: 위젯이 **절대** 열 사이(중앙)에 놓이지 않음. 항상 왼쪽 열(`x=0`) 또는 오른쪽 열(`x=6`)에만 스냅됨
- [ ] **오른쪽 빈 칸 자동 채움**: 오른쪽 열에 빈 칸이 있고, 아래쪽에 들어갈 수 있는 위젯이 있으면 **드롭 후** 해당 위젯이 위로 올라가 빈 칸을 채움 (gapless)
- [ ] **최종 레이아웃**: 드롭/추가/제거/크기 토글 후 항상 **구멍 없이** 위→아래로 밀집, 위젯끼리 **겹치지 않음**

## 0. 3타입 사이징 (FULL / TALL / NORMAL)

- [ ] **FULL**: 전폭 위젯(예: 고객 문의 현황, 전체 프로그램 진행 현황)이 **한 행 전체**를 차지 (`w=12`)
- [ ] **TALL**: 높은 반폭 위젯(예: 알림, 프로그램 일정)이 **NORMAL 높이의 2배**로 표시 (`w=6`, `h=TALL_HEIGHT`)
- [ ] **NORMAL**: 일반 반폭 위젯이 **기준 높이**로 표시 (`w=6`, `h=NORMAL_HEIGHT`)
- [ ] 한 행에 **전폭 1개** 또는 **반폭 최대 2개**만 존재 (2열 규칙)

## 1. 추가 / 드래그 / 순서 변경

- [ ] **위젯 추가**: 편집 모드 → "위젯 추가" → 목록에서 선택 후 추가 → 그리드에 나타나고 **밀집 배치**됨
- [ ] **드래그**: 카드 **헤더**만 잡고 드래그 가능, 본문 드래그로는 이동 안 됨
- [ ] **순서 변경**: 드래그로 위치 변경 후 놓으면 **리팩**되어 구멍 없이 위에서부터 채워짐

## 2. 밀집 배치 (Gapless packing)

- [ ] **드롭 후**: 빈 칸 없이 위→아래로 채워짐 (오른쪽만 비고 아래에 위젯 있는 경우 없음)
- [ ] **위젯 제거 후**: 제거된 자리가 남지 않고 위로 밀림
- [ ] **2열 유지**: 한 행에 최대 2개(왼쪽/오른쪽), 전폭 위젯은 한 행 전체 사용

## 3. 겹침 없음 (No overlap)

- [ ] **드롭 직후**: 위젯끼리 겹치지 않음
- [ ] **리팩 후**: 모든 위젯이 서로 겹치지 않는 최종 위치에 고정

## 4. 오버플로우 (No overflow)

- [ ] **긴 내용**: 카드 높이를 넘는 내용은 **카드 안에서만** 세로 스크롤
- [ ] **그리드 밖**: 위젯이 그리드 영역 밖으로 나가지 않음

## 5. 드래그 중 내부 클릭 비활성화

- [ ] **드래그 중**: 카드 본문(텍스트/버튼/링크) 클릭·스크롤·선택 안 됨
- [ ] **드래그 종료 후**: 본문 다시 클릭·스크롤 가능

## 5b. 드래그/드롭 후 규칙 유지

- [ ] **드롭 후 리오더**: 2열 규칙 유지, 밀집 배치 유지 (구멍 없음)
- [ ] **드롭 직후 겹침 없음**: 위젯끼리 겹치지 않음
- [ ] **카드 밖 오버플로우 없음**: 내용이 카드 밖으로 나가지 않음

## 6. 저장 / 취소

- [ ] **저장**: "저장" 후 새로고침해도 레이아웃 유지
- [ ] **취소**: "취소" 시 변경 전 레이아웃으로 복원

---

## 수동 검증 (x 정렬 / 저장 / 반응형)

1. **반폭 위젯 드래그 후 드롭**: 아무 위치에 놓아도 **항상** 왼쪽(`x=0`) 또는 오른쪽(`x=6`) 열에만 스냅됨. 중앙에 머물지 않음.
2. **위젯 추가/제거**: 추가·제거 후에도 위젯이 중앙에 오지 않음.
3. **새로고침**: 저장된 레이아웃을 불러와도 **x=0|6** 유지 (과거에 저장된 잘못된 x 값 없음).
4. **창 너비 변경** (Responsive 사용 시): 활성 브레이크포인트에서도 정렬 유지. (index2는 lg 단일 브레이크포인트 사용)

## 미드라인 기준 드롭 (pointer/시각 위치)

- [ ] **그리드 중앙선 왼쪽에 드롭**: 반폭 위젯이 **왼쪽 열** (`x=0`)에 배치됨.
- [ ] **그리드 중앙선 오른쪽에 드롭**: 반폭 위젯이 **오른쪽 열** (`x=6`)에 배치됨.
- [ ] **정확히 중앙선 위에 드롭**: **오른쪽 열** (`x=6`)에 배치됨 (오른쪽 편향).
- [ ] **드롭 후 밀집**: 리팩 후에도 구멍 없이 위→아래로 밀집.
- [ ] **저장 후 새로고침**: 위 규칙으로 저장된 레이아웃이 그대로 유지됨.
