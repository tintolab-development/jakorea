# IA 기반 멤버 권한 체계

본 문서는 IA PNG 기준으로 멤버 역할/타입과 메뉴 뎁스 구조를 정리한 문서입니다.

## 1. 표현 방식(레전드)
- 대메뉴 = 1depth
- 기능(버튼/셀렉트/인풋 등) = 2depth
- 상세/관리/신청 등 하위 페이지 = 3depth
- 관리자 IA는 일부 4depth까지 존재

## 2. 역할/타입 체계

### 2.1 최상위 역할(Role)
- 수강자
- 강사
- 관리자

### 2.2 역할별 하위 타입(Type)

#### 수강자
- 회원가입 가능
- 하위 타입:
  - 개인 학생
  - 학교(선생님)

#### 강사
- 회원가입 가능
- 하위 타입:
  - JA 강사진
  - 재미나이 강사진
  - 특강 강사(일회성)

#### 관리자
- 회원가입 없음
- 마스터 관리자 존재
- 마스터 관리자가 직원별 하위 관리자 계정 부여 가능

## 3. IA 기준 뎁스 구조(요약)

### 3.1 관리자 IA
#### 진입/계정
- 로그인: 마스터 관리자, 직원별 계정 부여
- 회원가입: 관리자 (실사용은 마스터 관리자에 의해 계정 부여)

#### 1depth(대메뉴)
- 메인 홈
- 프로그램 관리
- 회원관리
- 템플릿 관리
- 게시판 관리
- 후원사 관리
- 설문 관리
- 로그 관리

#### 2-4depth 대표 흐름
- 메인 홈
  - 검색(search bar)
  - 알림 리스트
  - 전체 프로그램 진행 현황(심사 완료/진행 예정/진행 중/진행 완료)
  - 배너
- 프로그램 관리
  - 검색/필터(select)
  - 프로그램 리스트
  - 프로그램 상세
  - 프로그램 엑셀 관리
  - 카테고리 예약/신청 상세/신청자 관리
- 회원관리
  - 전체 회원/학교(교사) 회원/강사 관리/봉사단 관리
  - 검색/추가/삭제/상세/관리
- 템플릿 관리
  - 파일 템플릿(공지/보고서/교육 계획 등)
  - SMS 문자 관리
  - 메일 관리
  - 배너 관리
- 게시판 관리
  - 공지사항/FAQ/문의하기
  - 검색/등록/삭제/상세/답변
- 후원사 관리
  - 등록/목록
- 설문 관리
  - 설문 생성/다운로드
- 로그 관리
  - 로그인 관리/이슈 관리

### 3.2 사용자(강사) IA
#### 진입/계정
- 로그인: JA 강사진 / 재미나이 강사진 / 특강 강사(일회성)
- 회원가입: 강사

#### 1depth(대메뉴)
- 메인 홈
- 진행 프로그램(수강)
- 마이페이지
- 공지사항
- FAQ
- 문의하기

#### 2-3depth 대표 흐름
- 메인 홈
  - 검색(search bar)
  - 알림 리스트(할인/일정/계절 안내)
  - 내 프로그램 현황(신청 완료/진행 예정/진행 중/진행 완료)
  - 배너
- 진행 프로그램(수강)
  - 검색/필터(select)
  - 프로그램 리스트
  - 프로그램 상세
  - 수강 신청/관심 등록
- 마이페이지
  - 개인정보 관리(개인정보/강사 이력)
  - 프로그램 관리(강의 프로그램 상세/멘토 조율/강의 보고/정산 요청)
  - 관심 프로그램(상세/관심 등록)
  - 정산 이력/정산 관리(대기/승인대기/이슈확인/지급완료)
- 공지사항/FAQ/문의하기
  - 검색/게시글 리스트

### 3.3 사용자(수강자) IA
#### 진입/계정
- 로그인: 개인 학생 / 학교(선생님)
- 회원가입: 수강자

#### 1depth(대메뉴)
- 메인 홈
- 진행 프로그램(수강)
- 봉사단
- 마이페이지
- 공지사항
- FAQ
- 문의하기

#### 2-3depth 대표 흐름
- 메인 홈
  - 검색(search bar)
  - 알림 리스트(할인/일정/계절 안내)
  - 내 프로그램 현황(신청 완료/진행 예정/진행 중/진행 완료)
  - 배너
- 진행 프로그램(수강)
  - 검색/필터(select)
  - 프로그램 리스트
  - 프로그램 상세
  - 수강 신청/관심 등록
- 봉사단
  - 검색
  - 봉사자 선정
  - 신청 상세/봉사 신청
  - 봉사 진행(진행 상세/교육 계획서 작성)
- 마이페이지
  - 개인정보 관리
  - 프로그램 관리(수강 프로그램/관심 프로그램)
  - 봉사 활동 관리(내 봉사 일정/봉사 참여 이력)
- 공지사항/FAQ/문의하기
  - 검색/게시글 리스트

## 4. 분리 원칙 요약
- 최상위는 수강자/강사/관리자로 구분
- 각 최상위 역할 하위에 타입을 둬 세부 구분
- 수강자와 강사는 회원가입 경로 존재
- 관리자는 회원가입 없이 마스터 관리자가 계정 생성
