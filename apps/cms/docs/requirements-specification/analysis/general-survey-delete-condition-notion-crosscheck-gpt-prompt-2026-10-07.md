## 현재 구현 사실 (FE, 2026-10-07 기준)

### 1. 설문 상태 판정

설문 상태는 서버의 설문 바인딩 응답 기간으로 FE가 계산한다.

| 조건 | 상태 |
|---|---|
| 바인딩 정보 없음 | 진행 중 (`in_progress`) |
| 현재 시각 < 응답 시작일시(`submissionStartAt`) | **시작 전** (`before_start`) |
| 현재 시각 > 응답 종료일시(`submissionEndAt`) | 종료 (`finished`) |
| 그 외 (시작일시 없음 포함) | 진행 중 (`in_progress`) |

### 2. 「설문조사 삭제」 버튼

- **활성 조건: 상태가 "시작 전"일 때만.**
- 응답이 0건이어도 이미 시작했거나 종료된 설문은 삭제할 수 없다.
- 삭제 확인 모달에서 `삭제`를 직접 입력해야 실제 삭제된다.
- 실제 삭제는 프로그램에 연결된 설문 바인딩을 지우는 동작이다(템플릿 자체 삭제 아님).

### 3. 본문 안내 화면이 뜨는 조건 (탭별로 다름)

| 탭 | 「아직 진행 전입니다」 안내 + 삭제 버튼이 뜨는 조건 | 그 외 |
|---|---|---|
| 설문조사 | **응답 수 0건** (상태와 무관) | 결과 그래프 |
| 만족도조사 | **상태가 시작 전** | 결과 그래프 (응답 0건이면 0으로 표시) |

→ 설문조사 탭은 "진행 중 + 응답 0건"일 때도 「진행 전입니다」 문구가 나오고 삭제 버튼은 비활성이다(재현 화면이 이 경우).

### 4. 상단 버튼 구성

| 상태 | 상단 버튼 |
|---|---|
| 시작 전 | 설문조사 공유, 설문조사 추가 |
| 진행 중 / 종료 | 결과 다운로드, 설문 양식 보기, 설문조사 공유, 설문조사 추가 |

- 결과 다운로드 활성 조건: 종료됐거나, 응답 수 ≥ 응답 대상 인원.

### 5. 설문 양식 보기 → 수정 가능 여부

- 상단 「설문 양식 보기」: 시작 전일 때만 수정 가능.
- 본문 안내 화면의 「설문 양식 보기」: **상태와 무관하게 수정 가능**으로 열린다.  
  (진행 중 + 응답 0건이면 상단은 수정 불가, 본문은 수정 가능으로 서로 다르다.)

## 교차검증 질문

Notion 기획과 비교해 아래 질문마다 답하라.

1. **삭제 가능 조건**은 무엇인가?
   - (a) 시작 전만 (현재 구현)
   - (b) 응답 0건이면 진행 중이어도 가능
   - (c) 기타 (기획 원문 인용)
2. **응답 시작일시가 비어 있는 설문**은 시작 전인가, 진행 중인가?
3. 설문조사 탭의 **「아직 진행 전입니다」 안내**는 언제 보여야 하는가?
   - 시작 전만인가, 응답 0건이면 항상인가?
   - 진행 중 + 응답 0건일 때 보여야 할 화면·문구가 기획에 따로 있는가?
4. 설문조사 탭과 만족도조사 탭의 **안내 화면 노출 조건이 달라도 되는가?**
5. **설문 양식 수정**은 어느 상태까지 허용되는가? (시작 전만 / 응답 0건이면 진행 중에도 허용)
6. 삭제 시 **확인 문구 입력(`삭제`)** 절차가 기획에 있는가?
7. 상단 버튼 구성·결과 다운로드 활성 조건이 기획과 일치하는가?
