# MVP v0.2 - Front Core (프론트 사용자 핵심 흐름)

> 요구사항 참조: §3 핵심 프로세스, FR-C01~C04, FR-D01, FR-E01~E03

## 목표
- 사용자(개인/학교/강사)가 **프로그램 탐색 → 신청 → 진행상태 조회**까지 완료
- 강사의 **마이페이지/일정/보고서** 기본 흐름 제공

### 요구사항 매핑
| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-C01 | "신청 참여" 페이지: 리스트 + 상세 + 신청 CTA | P1 |

### 구현 항목

#### 1) 프로그램 리스트 페이지 (`/programs`)
```typescript
// FR-C01: 프로그램 리스트 + 상세 진입 + 신청 CTA
interface ProgramListItem {
  id: string
  name: string
  sponsorName: string
  posterImage: string           // FR-C02: 포스터/키비주얼 이미지
  period: { startDate: string; endDate: string }
  applicationPeriod: { startDate: string; endDate: string }
  status: 'OPEN' | 'CLOSED' | 'COMPLETED'
}

// UI 구성
// - 썸네일 카드 형태
// - 필터: 모집중/마감/전체
// - 검색: 프로그램명/후원사
```

#### 2) 프로그램 상세 페이지 (`/programs/:id`)
```typescript
// FR-C02: 프로그램 상세 정보
interface ProgramDetail {
  id: string
  name: string                  // 프로그램 명
  sponsorName: string           // 후원사
  period: {                     // 진행기간
    startDate: string
    endDate: string
  }
  applicationPeriod: {          // 신청접수 기간
    startDate: string
    endDate: string
  }
  description: string           // 세부내용
  curriculum: string            // 커리큘럼
  educationSchedule: string     // 교육일정
  contact: {                    // 문의처
    email: string
    phone: string
  }
  posterImage: string           // 포스터/키비주얼 이미지
}

// UI 구성
// - 포스터 이미지 상단 배치
// - 신청하기 CTA 버튼 (로그인/회원가입 유도)
// - 신청 기간 표시 (마감 D-day)
```

#### 3) 신청하기 버튼 동작
```typescript
// FR-C01: "신청하기" 클릭 시 로그인/회원가입 유도
const handleApply = () => {
  if (!isLoggedIn) {
    // 로그인 페이지로 이동 (redirect 파라미터 포함)
    navigate(`/auth/login?redirect=/programs/${programId}/apply`)
    return
  }
  // 신청서 작성 페이지로 이동
  navigate(`/programs/${programId}/apply`)
}
```

### 화면

### 구현 항목

#### 1) 신청서 폼 페이지 (`/programs/:id/apply`)

const ApplicationForm = () => {
  const { user } = useAuth()

  if (user.role === 'SCHOOL') {
    return <SchoolApplicationForm />
  }
  if (user.role === 'INSTRUCTOR') {
    return <InstructorApplicationForm />
  }
  return <IndividualApplicationForm />

#### 2) 학교 신청서 폼 (§3.1)
```typescript
// §3.1 학교 신청 프로세스 - 신청서 작성
interface SchoolApplicationForm {
  // 기본 정보
  schoolName: string            // 학교명
  address: string               // 주소
  targetGrade: string           // 대상 학년
  classCount: number            // 학급 수
  studentsPerClass: number      // 학급별 인원
  instructorWaitingRoom: string // 강사 대기장소

  // 학생 명단 업로드 (FR-C03)
  studentListFile: File         // 엑셀 파일

  // 추가 정보 (신청 이후 공유)
  mealAvailable: boolean        // 급식 가능 여부
  canEatInWaitingRoom: boolean  // 대기실 내 취식 가능 여부
}
```

#### 3) 강사 신청서 폼 (§3.2)
```typescript
// §3.2 강사 프로세스 - 강의 신청
interface InstructorApplicationForm {
  preferredSchedule: string[]   // 선호 일정
  experience: string            // 강의 경력
  documents: {                  // 제출 서류
    resume?: File               // 이력서
    crimeCheckConsent?: File    // 성범죄조회동의서
  }
}
```

#### 4) 개인 신청서 폼
```typescript
interface IndividualApplicationForm {
  motivation: string            // 지원 동기
  // 템플릿 기반 커스텀 필드

```

#### 5) 파일 업로드 정책
```typescript
// 학생 명단 엑셀 업로드
const UPLOAD_POLICY = {

}
```
