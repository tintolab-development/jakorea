# 만족도 조사 플로우 가이드

## 📋 접근 경로

만족도 조사에 접근할 수 있는 방법은 다음과 같습니다:

### 1. 메뉴에서 직접 접근
- **경로**: 마이페이지 > 프로그램 관리 > 만족도 조사
- **URL**: `/programs/satisfaction`
- **설명**: 완료된 프로그램 목록을 확인하고 만족도 조사를 작성할 수 있습니다.

### 2. 프로그램 상세 페이지에서 접근
- **경로**: 마이페이지 > 프로그램 관리 > 강의 프로그램 > [프로그램 선택] > 만족도 조사 버튼
- **URL**: `/programs/my/:id`
- **설명**: 프로그램 상세 페이지에서 완료된 프로그램의 경우 "만족도 조사" 버튼이 표시됩니다.
- **조건**: 프로그램 상태가 `completed`이거나 종료일이 지난 경우에만 버튼이 표시됩니다.

## 🔄 만족도 조사 플로우

### Step 1: 만족도 조사 목록 페이지 접근
1. 메뉴에서 "만족도 조사" 클릭
2. 완료된 프로그램 목록이 표시됩니다
3. 각 프로그램의 만족도 조사 상태를 확인할 수 있습니다:
   - **미제출**: 아직 만족도 조사를 작성하지 않은 프로그램
   - **제출 완료**: 이미 만족도 조사를 제출한 프로그램

### Step 2: 만족도 조사 작성
1. 목록에서 프로그램명을 클릭하거나 "작성" 버튼 클릭
2. 만족도 조사 모달이 열립니다
3. 다음 항목을 입력합니다:
   - 프로그램 만족도 (1-5점)
   - 내용 만족도 (1-5점)
   - 강사 만족도 (1-5점)
   - 종합 만족도 (1-5점)
   - 장점 (선택)
   - 개선사항 (선택)
   - 추가 의견 (선택)
4. "제출하기" 버튼 클릭

### Step 3: 만족도 조사 수정
1. 이미 제출한 프로그램의 경우 "수정" 버튼이 표시됩니다
2. 수정 버튼 클릭 시 이전에 입력한 내용이 자동으로 채워집니다
3. 내용을 수정한 후 다시 제출할 수 있습니다

## 📊 만족도 조사 대상 프로그램

만족도 조사를 작성할 수 있는 프로그램은 다음 조건을 만족해야 합니다:

1. **프로그램 상태**: `status === 'completed'` 또는 종료일이 지난 프로그램
2. **매칭 상태**: 해당 강사가 매칭된 프로그램
3. **프로그램 완료**: 프로그램이 진행 완료된 상태

## 🔍 Mock 데이터

현재 만족도 조사는 Mock 데이터를 사용합니다:

- **제출 기록**: 로컬 state에 저장되며, 페이지 새로고침 시 초기화됩니다
- **프로그램 목록**: `getMyPrograms` API를 통해 완료된 프로그램을 가져옵니다
- **필터링**: `status: 'completed'` 필터를 사용하여 완료된 프로그램만 표시합니다

## ⚠️ 주의사항

1. **데이터 지속성**: 현재는 로컬 state에만 저장되므로 페이지를 새로고침하면 제출 기록이 사라집니다
2. **API 연동 필요**: 실제 운영 환경에서는 API를 통해 만족도 조사 데이터를 저장하고 불러와야 합니다
3. **권한**: 강사(INSTRUCTOR) 권한만 만족도 조사를 작성할 수 있습니다
