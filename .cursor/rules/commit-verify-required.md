# 커밋 전 검증 필수 (--no-verify 지양)

커밋/병합 시 **타입·린트 검사를 반드시 통과**해야 합니다. pre-commit 훅을 건너뛰지 않습니다.

## 🔴 절대 규칙

### 1. --no-verify 사용 금지

- **`git commit --no-verify` 사용을 지양한다. 사용하지 않는다.**
- pre-commit 훅(typecheck, lint 등)은 품질 보장을 위해 존재하므로 건너뛰지 않는다.
- 병합·긴급 픽스 등 어떤 이유로도 `--no-verify`로 훅을 스킵하지 않는다.

### 2. 커밋 전 필수 실행

- **커밋/푸시 전에 반드시 다음을 실행하고, 에러가 없을 때만 커밋한다.**
  ```bash
  pnpm typecheck   # 전체 타입 체크
  pnpm lint        # 린트 검사
  ```
- 타입 에러나 린트 에러가 있으면 **수정 후** 다시 검사하고 통과한 뒤 커밋한다.

### 3. 병합 시

- 다른 브랜치를 merge 할 때 충돌 해결 후에도 **동일하게 typecheck/lint를 실행**하고, 실패하면 해당 브랜치의 타입/린트 오류를 먼저 해결한 다음 병합 커밋을 완료한다.

## 요약

| 하지 말 것 | 해야 할 것 |
|-----------|------------|
| `git commit --no-verify` | 커밋 전 `pnpm typecheck` 및 `pnpm lint` 실행 |
| 훅 실패 시 스킵하고 커밋 | 에러 수정 후 훅이 통과할 때만 커밋 |
