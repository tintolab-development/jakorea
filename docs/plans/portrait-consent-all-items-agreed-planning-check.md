- 현재: 초상권 1·2·3번 중 하나라도 미동의면 「부분 동의」

## 1. 기획 확정 기준

### 1-1. 동의 상태 표시 기준 (관리자 화면)

| 동의서 | 동의 | 부분 동의 | 미동의 |
|---|---|---|---|
| 초상권 | 1·2·3번 모두 동의 | 1·2번 동의, 3번(홍보) 미동의 | 1번 또는 2번 미동의 |
| 지급조서 사전 동의서 | 전부 동의 | 제3자 제공·이용 미동의 | 미작성·철회 |
| 영수증 사전 동의서 | 전부 동의 | 제3자 제공·이용 미동의 | 미작성·철회 |
| 마케팅 정보 수신 | 동의 | 없음 | 미동의 |
| 그 밖의 항목 | 동의 | 없음 | 미동의 |

공통 규칙 (관리자 0483·0850번)
- 기간제 동의서의 **유효기간이 지나면** 위 상태와 관계없이 **「동의 만료」**로 표시합니다. 「동의 만료」는 유효기간 경과에만 씁니다.
- 재동의 안내 문구 없이 **상태값만** 표시합니다.
- 「동의 만료」면 **만료일**, 철회면 **철회일**을 함께 표시합니다.
- **실제 동의가 확인된 항목만 「동의」**로 표시합니다.
- 표기는 띄어서 **「부분 동의」**입니다.

## 3. 화면별 현재 표시와 목표 표시

「현재 표시」는 A단계 반영 후 로컬 기준입니다.

### 3-1. 초상권 (PORTRAIT_RIGHTS)

| 상태 | 서버 값 (현재 계약) | 현재 표시 | 목표 (관리자) | 목표 (사용자) | 일치 |
|---|---|---|---|---|---|
| 1·2·3 모두 동의 | `agreed=true`, `allItemsAgreed=true`, `programEligible=true` | 동의 | 동의 | 동의 | ✅ |
| 3번만 미동의 | `agreed=true`, `allItemsAgreed=false`, `programEligible=true` | 부분 동의 | 부분 동의 | 결정 ① | ✅ 관리자 / 사용자 결정 대기 |
| 1 또는 2번 미동의 | `agreed=true`, `allItemsAgreed=false`, `programEligible=false` | 부분 동의 | **미동의** | **미동의** | ❌ BE-3 필요 |
| 미동의 | `agreed=false`, `consentStatus=DISAGREED` | 미동의 | 미동의 | 미동의 + [동의서 작성] | ✅ |
| 철회 | `status=WITHDRAWN` | 미동의 | 미동의 + 철회일 | 미동의 + 철회일 | 철회일 ❌ (BE-5, FE-10) |
| 만료 예정 | `expiresAt`까지 1개월 이내 | 안내 없음 | 상태값만 | 동의 + 만료 예정 안내 | ❌ (FE-9) |
| 기간 만료 | `expired=true` | Platform: 동의 만료 + 「프로그램을 신청하시려면 다시 동의해 주세요.」 / CMS: 동의 만료 \| 만료일 | **동의 만료** + 만료일 | **동의 만료** + 안내 문구 | ✅ (FE-4, 배지 색은 D1) |
| 약관 개정 재동의 | `reconsentRequired` 또는 `policyUpdated` (`expired` 아님) | 미동의 또는 부분 동의 + 초상권 만료 문구 | 결정 ④ | 결정 ④ | 결정 대기 |
| 판정 불가 과거 기록 | `agreed=true`, `allItemsAgreed=null` | 부분 동의 | 결정 ③ | 결정 ② | 결정 대기 |

## 4. 수정 요청 상세

### 4-1. BE 수정 요청

#### BE-1. 초상권 외 항목에 `consentStatus=PARTIAL`을 보내지 않기

- 현상 (로컬 회원 190001, `GET /api/portal/me/consents`, `GET /api/admin/users/{memberId}/consents`)

  | consentType | agreed | consentStatus | 현재 화면 |
  |---|---|---|---|
  | SERVICE_TERMS | true | PARTIAL | 부분 동의 |
  | PRIVACY_COLLECTION | true | PARTIAL | 부분 동의 |
  | MARKETING | true | PARTIAL | 부분 동의 |
  | TEACHER_INFO_COLLECTION | true | PARTIAL | 부분 동의 |

- 요청: 초상권 외 항목은 `consentStatus=null`. 기존 요청서 계약("비초상권은 null")과도 같습니다.
- FE 영향: BE가 수정되면 FE 수정 없이 「동의」로 표시됩니다.

#### BE-2. 미동의·만료 항목에 `consentStatus=PARTIAL`을 보내지 않기

- 현상 (회원 190001)

  | consentType | agreed | consentStatus | 현재 화면 |
  |---|---|---|---|
  | FACILITATOR_PLEDGE | false | PARTIAL | 부분 동의 + 「교육진행자 활동을 위해 다시 작성해 주세요.」 |
  | ADMINISTRATIVE_INFO_CONSENT | false | PARTIAL | 부분 동의 |

- 요청: 미동의·철회는 `PARTIAL`을 보내지 않음. 만료 여부는 `expired`로 구분 가능해야 합니다.

#### BE-3. 초상권 1·2번 미동의를 표시용으로 구분할 값

- 현재 `allItemsAgreed=false`는 「3번만 미동의」와 「1 또는 2번 미동의」를 모두 포함합니다.
- 기획은 두 경우를 「부분 동의」와 「미동의」로 나눕니다.
- 선택지 (BE와 합의 필요)

  | 안 | 내용 | 장점 | 확인할 점 |
  |---|---|---|---|
  | A | FE가 `programEligible`로 구분 (`false`이면 미동의) | BE 변경 없음 | 요청서가 `programEligible`을 "참여 게이트 전용"으로 정했음. 다른 이유(보호자 미인증, 동의 기간 만료 등)로 `false`가 되는 경우가 없는지 BE 확인 필요. 만료된 동의는 유효한 동의로 보지 않으므로 만료 시 `false`가 될 수 있음 |
  | B | BE가 표시용 상태값 추가 (예: `displayStatus=AGREED/PARTIAL/DISAGREED/EXPIRED`) | 화면 판정이 서버 한 곳으로 모임 | 응답 필드 추가, 요청서 개정 |
  | C | BE가 항목별 동의 값 추가 (예: `item1Agreed`, `item2Agreed`, `item3Agreed`) | 기획 문서와 1:1 대응 | 필드 3개 추가 |

- FE 제안: 지급조서·영수증(BE-4)도 같은 구조가 필요하므로 **B안**을 권장합니다.

#### BE-4. 지급조서·영수증 사전 동의서의 「부분 동의」 판정 값

- 현재 응답에 「제3자 제공·이용 동의」 여부가 없어 FE가 구분할 수 없습니다.
- 요청: BE-3과 같은 방식으로 표시 상태 또는 항목 동의 값을 내려 주세요.
- 대상 응답: `GET /api/portal/me/consents`, `GET /api/admin/users/{memberId}/consents`, `GET /api/admin/users/{memberId}/consent-records`, CMS 회원 상세 `termsAgreements[]`

#### BE-5. 철회일 필드 추가

- 관리자 화면(0483·0850번)과 사용자 화면(0061번) 모두 철회 시 철회일을 표시해야 합니다.
- 현재 응답 필드
  - 만료일: `expiresAt` 있음 → FE에서 바로 표시 가능
  - 철회일: `MemberPortalConsentSummary`, `MemberConsentRecordResponse`, `TermsAgreementRow`, Platform `GET /api/portal/me/consents` 모두 **없음**
- 요청: 사용자·관리자 동의 응답에 철회일(예: `withdrawnAt`)을 추가해 주세요.

#### BE-6. 만료가 없는 항목에 만료일 보내지 않기

- 현상 (회원 190001, `GET /api/portal/me/consents`)

  | consentType | expiresAt |
  |---|---|
  | SERVICE_TERMS | 2027-10-31 |
  | PRIVACY_COLLECTION | 2027-10-31 |
  | MARKETING | 2027-10-31 |
  | TEACHER_INFO_COLLECTION | 2027-10-31 |

- 기획상 서비스 이용약관·개인정보 수집·이용·교사 정보 동의는 「서비스 탈퇴 시까지」, 법정대리인 동의는 「회원 탈퇴 또는 만 14세 이상 회원 전환 시까지」, 마케팅은 만료 적용 대상이 아닙니다.
- 요청: 위 항목에는 `expiresAt`을 보내지 않음(`null`).
- FE 영향: FE는 만료 예정·「동의 만료」를 기간제 6종에만 적용하므로 화면 오표시는 막지만, 응답 계약은 기획과 맞춰야 합니다.
