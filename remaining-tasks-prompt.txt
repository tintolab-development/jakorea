### 2. 서비스 레이어 훅 래핑 (의존성 분리) (High Priority)
컴포넌트에서 직접 호출하는 서비스 함수들을 커스텀 훅으로 래핑:

주요 서비스:
- applicationService (create, update, delete, getById 등)
- programService (getAllSync, getByIdSync 등)
- reportService (review, approve, reject 등)
- settlementService (calculate, approve, reject 등)
- matchingService (confirm, cancel 등)
- instructorService, schoolService, userService 등

각 서비스별로 hooks 폴더에 훅 생성:
- features/application/hooks/use-application-service.ts
- features/program/hooks/use-program-service.ts
- features/report/hooks/use-report-service.ts
등등...

훅 패턴:
```typescript
export function useApplicationService() {
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState<Error | null>(null)

  const create = useCallback(async (data: CreateApplicationData) => {
    setLoading(true)
    setError(null)
    try {
      const result = await applicationService.create(data)
      return result
    } catch (err) {
      setError(err as Error)
      throw err
    } finally {
      setLoading(false)
    }
  }, [])

  return { create, update, delete: deleteApp, loading, error }
}
```

그리고 컴포넌트에서 직접 service 호출하는 부분을 훅으로 교체:
- report-detail-drawer.tsx: reportService.review() → useReportService()
- application-path-list-page.tsx: createPath(), updatePath() → useApplicationPathService()
- 기타 모든 서비스 직접 호출 부분
